# 隱私權政策

**Apnea Comp**

*最後更新: 2026年9月18日*

---


## 1. 簡介

本隱私權政策說明 **Apnea Comp** 行動應用程式（以下簡稱「我們」、「本應用程式」）在您使用我們的服務時如何收集、使用及保護資訊。本應用程式是一款大會管理工具，專為參加 AIDA 認證大會的自由潛水賽事主辦者、裁判、工作人員及運動員而設計。

使用本應用程式即表示您同意本政策中所述的處理方式。

---


## 2. 我們收集的資訊

### 2.1 帳戶資訊

當您建立帳戶時，我們會收集：

- **電子郵件地址** — 用於身分驗證與帳戶復原
- **顯示名稱（Display name）** — 向同一賽事的其他參與者顯示
- **密碼** — 透過我們的身分驗證供應商（Supabase Auth）以安全雜湊形式儲存。我們絕不以明文儲存密碼。


**使用 Apple 或 Google 登入。** 您可以使用您的 Apple 或 Google 帳戶登入，而非電子郵件與密碼登入。當您這麼做時，我們會從 Apple 或 Google 接收您的**姓名**與**電子郵件地址**，以建立或識別您的帳戶。若您使用 **Sign in with Apple** 並選擇隱藏您的電子郵件，Apple 會提供一個私人轉發（relay）電子郵件地址，而非您的真實地址，我們會以與任何其他電子郵件相同的方式使用它。我們絕不會接收您的 Apple 或 Google 密碼 — 登入由該供應商與我們的身分驗證供應商（Supabase Auth）共同處理。


### 2.2 個人資料資訊（選填）

- **個人資料圖片** — 若您選擇上傳。該圖片對您加入的任何賽事的其他成員可見，並在活動紀錄中被參照（見第 2.6 節）。

### 2.3 運動員帳戶連結（針對運動員）

若您註冊為運動員以查看出發名單及您本人的成績，本應用程式將儲存：

- **AIDA 運動員 UUID** — 來自 AIDA International 的永久識別碼，用於將您的帳戶與您在賽事 Start List 中的出場紀錄進行配對。僅在賽事主辦者的邀請碼經過驗證，或您的姓名與賽事 Start List 配對並獲得核准之後，該 UUID 才會與您的帳戶建立關聯。
- **同步的顯示名稱** — 您在 AIDA Start List 中公布的姓與名（First/Last name），在連結步驟中複製到您的個人資料
- **AIDA 搜尋查詢** — 當您使用「Find me on AIDA」功能尋找您的運動員資料時，您輸入的姓名會被傳送到 AIDA International 的公開運動員搜尋服務，以擷取相符的資料。僅傳輸您輸入的文字；不包含任何帳戶憑證（見第 4.1 節）。
- **AIDA 公開檔案查詢** — 當任何人在本應用程式中開啟某位運動員的檔案時，本應用程式會使用該運動員的 AIDA UUID，向 AIDA International 網站請求該運動員的公開檔案頁面與公開成績頁面，並顯示 AIDA 在該處公布的歷年成績、國家／洲際／世界排名、參賽紀錄與檔案照片。不會傳送任何帳戶憑證，我們也不會儲存副本：查詢結果僅在本次工作階段中保留於本應用程式的記憶體內，並在本應用程式重新啟動時被捨棄。

此資料僅保留在您本人的個人資料中，用於為您參加的賽事啟用唯讀存取。

### 2.4 運動員比賽資料（自 AIDA 載入）

當賽事主辦者自 AIDA International 載入賽事時，本應用程式將儲存：

- **運動員姓名**（姓與名）
- **性別**
- **國籍**
- **項目**（STA、DYN、CWT 等）
- **公布成績（Announced Performance, AP）**
- **個人最佳成績（Personal Best, PB）**
- **比賽成績**（RP、裁判卡片、處罰原因、REMARKS）
- **積分（Points）** — 根據成績計算得出的大會積分
- **報名類型（Entry type）** — 區分某筆報名是一般出發、*opener*（不計入排名且不傳送至 AIDA 的熱身報名），或是 *re-swim*（經申訴核准的重新表現）
- **有效性旗標** — 當運動員進行 re-swim 時，原始報名會被標記為 *invalidated*，從而被排除在排名之外；但其仍會顯示在 Results 中
- **報到狀態** — 運動員為待報到、已報到、Late Check-in（逾時報到）或 DNS（未出場），以及報到時間。依 AIDA 規則，Late Check-in 或 DNS 會伴隨比賽處罰；且一旦報到截止時間過後，本應用程式可能會自動將運動員標記為逾時報到。本應用程式在報到時會顯示簽名板，以便運動員確認出席，但**簽名影像本身絕不會被儲存** — 僅儲存簽名已發生這項事實。
- **風險標記** — 賽事工作人員可對運動員設定的安全旗標（見第 2.11 節）

除報到狀態與風險標記外，上述資訊來源於 **AIDA International 的公開比賽紀錄**（透過其官方 API）。報到狀態與風險標記則直接在本應用程式內記錄。

### 2.5 我們不收集的資訊

我們明確**不**收集或儲存：

- 運動員的電子郵件地址，但擁有自己帳戶的運動員本人的電子郵件地址，以及向主辦者顯示的賽事成員電子郵件地址除外
- 運動員的電話號碼，但您選擇提交的醫療診斷書上所載醫師的聯絡電話除外
- 運動員的實際地址
- 報到簽名影像（僅儲存布林旗標）
- 使用者的位置資料
- 廣告或跨應用程式追蹤識別碼，以及將您的資料用於廣告的任何行為
- 瀏覽紀錄
- 您裝置中的聯絡人

我們確實會儲存您登入所用裝置的一組隨機產生的識別碼。它由本應用程式產生，並非衍生自任何硬體識別碼，且僅用於確保同一帳戶同時只在一部裝置上登入，以及在賽事期間讓 Speaker Mode 裝置保持登入狀態。

我們不儲存運動員的臉部照片。您本人上傳的個人資料圖片會被儲存（第 2.2 節）；而 AIDA International 公布的運動員檔案照片，則是在開啟檔案時由本應用程式自 AIDA 的公開網站載入並顯示（第 2.3 節）。

### 2.6 活動紀錄

為支援大會期間的營運透明度，本應用程式會記錄在賽事內執行的重要操作：

- **我們記錄的內容** — 裁判結果的輸入與更正、日程調整（OT Delay）、報到操作（包含系統自動標記逾時報到）、Setup 與 Start List 變更、通知的傳送與取消、成員角色變更，以及對運動員醫療診斷書所執行的操作（作廢、復原，以及在報到時確認先前發生過的黑視）。
- **每筆紀錄項目包含的內容** — 使用者的顯示名稱、個人資料圖片 URL（如已設定）、操作類型、受影響的運動員姓名（如適用）、時間戳記，以及描述變更內容的結構化明細紀錄（例如變更前與變更後的成績值）。
- **另行保存的判定稽核紀錄** — 對已儲存裁判結果的每一次變更，包括被伺服器擋下的嘗試，都會另外記錄在一份稽核資料表中，其中保存執行操作者的電子郵件地址以及變更前後的值。此機制的存在是為了在成績發生爭議時能夠還原經過。它僅供該賽事的 Organizer 與 Main Judge 讀取，且在本應用程式中沒有對應畫面。
- **可見範圍** — 活動紀錄畫面提供給 Organizer 與 Main Judge 使用。紀錄項目儲存在賽事內，且在技術上可由同一賽事中已核准的成員透過我們的 API 讀取。
- **保留期限** — 紀錄項目與判定稽核紀錄會在賽事紀錄存在期間一併保留。它們並未透過資料庫限制條件與賽事繫結，因此刪除賽事並不會自動移除它們；請參見第 5 節。

### 2.7 推播通知資料

為將與賽事相關的通知傳遞至您的裝置，本應用程式將儲存：

- **OneSignal Subscription ID** — 由我們的推播通知供應商（OneSignal）核發的裝置專屬識別碼。僅用作通知的目標地址。
- **OneSignal external user ID** — 您的帳戶 ID，與 Subscription ID 關聯，以便無論使用哪一台裝置，都能向您的帳戶傳送通知。
- **Subscription 時間戳記** — 最後更新時間，用於偵測失效的訂閱

這些值儲存在您的帳戶個人資料中。當您登出本應用程式、當另一個帳戶在同一裝置上登入時，Subscription ID 會被清除；當 OneSignal 回報該訂閱不再有效時（例如本應用程式被解除安裝或通知權限被撤銷之後），也會自動清除。

**注意：** Apnea Comp 先前使用 Firebase Cloud Messaging（FCM）進行推播傳遞。自 2026 年 5 月起，推播通知基礎架構已遷移至 OneSignal。有關所涉第三方供應商的詳細資訊，請參見第 4.3 節。

### 2.8 裝置本機儲存

本應用程式基於兩個目的在您的裝置上於本機儲存有限的資料：

**離線緩衝（Judge 結果）**

為在網路連線間歇性中斷時（在泳池及深度場地常見）仍能繼續操作，本應用程式可能會在裁判結果送達我們的伺服器之前，將其暫時保存在您裝置的記憶體中：

- **位置** — 僅在本應用程式執行時的記憶體中。離線緩衝的裁判結果不會寫入裝置的持久儲存。
- **時機** — 在裝置離線時嘗試儲存裁判結果時自動進行。
- **時長** — 直到本應用程式將結果與我們的伺服器同步為止，這會在網路恢復後數秒內自動完成。
- **可見範圍** — 離線緩衝的結果僅在建立它們的裝置上可見，直到同步成功。同一賽事中的其他裝置看不到它們。
- **限制** — 若在同步完成之前本應用程式被強制關閉或裝置重新啟動，離線緩衝的結果將遺失。本應用程式會在受影響的項目上顯示「⛔ Offline」徽章，並警告使用者在項目處於待處理狀態時不要結束本應用程式。

**登入便利（Remember Email / Password）**

登入畫面提供兩個選用切換開關，可將憑證儲存於本機，以便在後續登入時預先填入：

- **Remember email** — 如啟用，您的電子郵件地址將儲存到裝置的標準本機儲存（Android 上為 SharedPreferences，iOS 上為 NSUserDefaults）。
- **Remember password** — 如啟用，您的密碼將儲存到裝置的**安全金鑰庫**（iOS Keychain / Android EncryptedSharedPreferences，AES-256，由作業系統加密）。它絕不會以明文儲存，也絕不會傳輸到我們的伺服器或任何第三方。它僅用於在同一裝置上預先填入登入表單並還原您的工作階段。
- **位置** — 僅在您的裝置上。此資訊不會傳輸到我們的伺服器或任何第三方。
- **如何移除** — 在下次登入時取消勾選該選項、登出本應用程式（這會清除已儲存的憑證），或解除安裝本應用程式。

**顯示偏好設定（Display Preferences）**

您的主題選擇（淺色 / 深色 / 系統）與應用程式語言會於本機儲存（SharedPreferences），以便本應用程式在每次啟動之間記住它們。這些僅為偏好設定，不包含任何個人資訊。

離線緩衝、登入便利及顯示偏好設定儲存均不會向任何第三方傳輸資料。

### 2.9 申訴（Protest）資料

當依據 AIDA 大會規則（規則手冊 17.7）提交申訴時，本應用程式會儲存一筆 protest 紀錄，其中包含：

- **申訴理由** — 由提交申訴者輸入的自由文字
- **運動員簽名**以及（如適用）**Jury 簽名** — 以手繪影像形式擷取並（以 base64 編碼）儲存在 protest 紀錄內。與報到簽名板不同，由於已簽署的申訴是官方比賽紀錄的一部分，因此**申訴簽名會被保留**。
- **產生的申訴表單** — 一份嵌入了理由與簽名的 PDF，儲存在我們的後端檔案儲存（Supabase Storage）中
- **決定與修改** — jury 的決定（accepted / rejected / withdrawn），以及如被接受，修改後的成績（card、RP、remarks）

**可見範圍** — protest 紀錄對賽事的工作人員（Organizer、Main Judge、Judge）以及該申訴所涉及的運動員可見。申訴活動會觸發推播通知（見第 3 節）。

### 2.10 提交文件（同意書與醫療診斷書）

當運動員加入賽事時，本應用程式可能會收集並儲存主辦者要求的同意與資格相關文件：

- **大會報名表** — 性別、出生日期、出生國家、國籍、各項目的個人最佳成績，以及**您選擇申報的健康相關病史**（最近一次壓力損傷／氣壓傷日期、最近一次黑視（black-out）日期、最近一次健康檢查日期）。
- **肖像權同意書**與**責任免除同意書** — 您的姓名、賽事名稱與地點、簽署日期，以及您手繪的簽名。
- **醫療診斷書（選填）** — 一份醫師的適格性聲明，包含檢查／開立日期以及醫師的姓名、電話號碼與手繪簽名。由於它證明您的健康狀況，因此屬於**敏感健康資訊**。醫療診斷書有效期為一年，並可依您的選擇儲存於您本人的個人資料中，以便在未來的賽事中重複使用。
- **簽名** — 運動員、見證人與醫師的簽名以手繪影像形式擷取，並嵌入所產生的表單中。與報到簽名不同，這些簽名會作為同意紀錄的一部分**保留**。
- **上傳的檔案** — 若您以照片或掃描檔提交文件，而非在應用程式中填寫，該影像檔案將被儲存。
- **產生的 PDF** — 您在應用程式中完成的表單會被轉為 PDF，並儲存在我們的後端檔案儲存（Supabase Storage）中。

**可見範圍** — 已提交的賽事文件對賽事的 Organizer 與 Main Judge 可見以供驗證，他們也可將其以 ZIP 封存檔的形式批次下載。若您申報了傷害或黑視日期，系統會提示工作人員手動驗證您的醫療診斷書。

**提醒** — 若必填文件未在賽事前一天之前提交，您可能會收到列出缺漏文件的推播通知。

**我們為何保留這些資料** — 醫療診斷書以及在大會報名表上申報的健康病史，係基於您的**明確同意**進行處理；該同意是在您選擇填寫並提交表單時所給予。您可以隨時透過第 11 節所載的聯絡方式撤回該同意，但依 AIDA 規則，主辦者屆時可能無法准許您參加大會。

### 2.11 賽事期間的安全與醫療紀錄

自由潛水大會攸關安全，且 AIDA 規則要求特定醫療事件必須被記錄並加以處置。因此本應用程式會儲存：

- **風險標記** — Organizer、Main Judge、Judge 或 Safety 工作人員可在運動員表現前對其設定的安全旗標（無／黃／橙／紅），以便安全潛水員與裁判預作準備。該旗標在本應用程式中以及已配對的 Apple Watch 上對賽事工作人員可見，並與該運動員的賽事報名一併儲存。
- **黑視（black-out）後續紀錄** — 若運動員發生黑視或被標記為高風險，Organizer 或 Main Judge 會記錄後續判斷（「已放行」或「需重新體檢」）、選填的醫療備註、由誰作出判斷以及判斷時間。該紀錄會在同一賽事後續日程的報到時再次顯示。
- **醫療診斷書作廢** — 若需重新體檢，Organizer 或 Main Judge 可作廢您的醫療診斷書。我們會在賽事提交件以及儲存於您個人資料中的副本上，一併儲存作廢時間、作廢者與所填寫的原因，並以推播通知告知您。原因本身不會包含在通知中。作廢可由相同角色撤銷。

**我們為何保留這些資料** — 為安全地舉辦賽事並遵守 AIDA 大會規則。由於這屬於健康資訊，我們係在攸關安全的運動中，為保護運動員與安全工作人員之重大利益所必要的範圍內進行處理，並且這是您參加 AIDA 賽事時所同意的大會規則所要求。存取權限僅限於賽事的 Organizer 與 Main Judge；風險標記則另可由安全相關工作人員查看。這些紀錄作為賽事紀錄的一部分保留，並在賽事被刪除時刪除。

### 2.12 公告與工作人員訊息

本應用程式包含賽事公告板（Board，由 Organizer 或 Main Judge 撰寫、賽事中所有人皆可閱讀的公告）與推播（Dispatch，由賽事工作人員傳送給選定工作人員的訊息）。對於每則訊息，我們會儲存內文、傳送者的姓名與電子郵件地址、時間，以及 — 針對 Dispatch — 收件人的電子郵件地址清單。當訊息以推播通知形式傳送時，其文字會原封不動地傳遞給 OneSignal，且不會被翻譯。訊息屬於賽事的一部分，並在賽事被刪除時刪除。

### 2.13 排除紀錄

若 Organizer 將您從賽事中移除，本應用程式會保留該次排除的紀錄，以免本應用程式的自動運動員配對將您重新加入，從而在無人察覺的情況下推翻 Organizer 的決定。該紀錄包含您的電子郵件地址、您的 AIDA 運動員 ID、您姓名的正規化形式、執行排除者、Organizer 所填寫的任何原因以及時間。即使您已不再是成員，該紀錄仍會為該賽事保留，且不會依排程移除。Organizer 可透過向您核發新的個人邀請碼來推翻它。請參見第 5 節。

### 2.14 Apple Watch 隨附應用程式

本應用程式包含一個 Apple Watch 隨附應用程式，可顯示 Start List，並在 Apple Watch Ultra 上於您潛入水中時顯示含深度、潛水時間與水溫的潛水畫面。手錶會為此要求「動作與健身」（Motion & Fitness）權限。**深度、水溫與潛水時間僅顯示於手錶上** — 它們不會被傳送到手機、我們的伺服器、AIDA 或任何其他人，也不會被儲存。資料為單向流動：由手機將賽事名稱、您的角色、您的姓名與 Start List（包含安全風險標記）傳送至手錶。

我們使用所收集的資訊來：

- 將裁判結果提交回 AIDA International（在賽事主辦者設定後）
- 在賽事工作人員使用的裝置之間即時同步資料
- 維護活動紀錄，以實現賽事內的營運透明度
- 管理依據 AIDA 大會規則提交的申訴，包括擷取簽名以及記錄 jury 的決定與任何修改後的成績
- 檢查伺服器端的最低支援應用程式版本（一個公開的設定值），以提示使用者更新；此檢查不傳輸任何個人資料
- 透過 OneSignal 傳送推播通知，包括：
  * **手動通知** — 由賽事主辦者觸發（出發名單發布、非正式成績、正式成績）
  * **自動通知** — 由賽事狀態觸發（影響特定運動員的日程變更 / OT Delay；向尚未報到的運動員傳送的報到截止提醒；申訴活動 — 已提交、等待運動員簽名、已決定）；由 Organizer 或 Main Judge 發布的 Board 公告；由賽事工作人員發送給您的 Dispatch 訊息；缺漏文件提醒；以及您的醫療診斷書已被作廢的通知。Board 與 Dispatch 的文字會原封不動地傳送，且不會被翻譯。
  * 通知文字會在地化為接收者的應用程式語言，但 Board 與 Dispatch 的訊息內文除外
- 記錄依 AIDA 規則舉辦賽事所需的安全與醫療資訊（見第 2.11 節）
- 保留 Organizer 已從賽事中移除之參與者的紀錄，以免自動運動員配對將其重新加入（見第 2.13 節）
- 確保同一帳戶同時只在一部裝置上登入

我們**不會**將您的資訊用於廣告、行銷或向第三方銷售。

## 5. 資料保留

- **帳戶資料** — 在您的帳戶存在期間保留。刪除您的帳戶會移除您的登入憑證與個人資料（顯示名稱、個人資料圖片、已連結的 AIDA 運動員 UUID、推播訂閱與語言設定）。而構成賽事官方比賽紀錄一部分的資料 — 您的賽事成員資格、成績、報到、活動紀錄項目、申訴與已提交文件 — 係以您所使用的電子郵件地址加以識別，不會因帳戶刪除而移除；它們會依其各自的排程移除（賽事刪除，或下列文件保留期限）。若您希望更早移除這些資料，請透過第 11 節所載的聯絡方式與我們聯繫。
- **賽事資料**（運動員、成績、報到狀態、申訴、文件、公告與工作人員訊息、黑視後續紀錄） — 在賽事主辦者刪除賽事時自動刪除。
- **活動紀錄與判定稽核紀錄** — 在賽事紀錄存續期間保留。它們並未透過資料庫限制條件與賽事繫結，因此刪除賽事並不會自動移除它們；若您需要移除它們，請透過第 11 節所載的聯絡方式與我們聯繫。
- **排除紀錄** — 若 Organizer 將您從賽事中移除，我們會保留該次排除的紀錄（您的電子郵件地址、您的 AIDA 運動員 ID 與姓名索引鍵、執行移除者以及所填寫的任何原因），以免自動重新註冊推翻 Organizer 的決定。此紀錄無限期保留，且只能由該 Organizer 核發新的個人邀請碼加以推翻。
- **批次下載封存檔** — 當 Organizer 或 Main Judge 將某一賽事的所有文件或申訴表單以 ZIP 形式下載時，該封存檔會被寫入我們的檔案儲存，並透過一個 10 分鐘後失效的連結分享。文件封存檔會在一天後刪除；申訴封存檔則在 30 天後刪除。
- **申訴資料**（理由、簽名、決定） — 作為賽事的一部分保留，並在主辦者刪除賽事時隨賽事一同刪除。儲存在我們檔案儲存中的產生的申訴 PDF 會在單筆申訴被刪除時移除，且在任何情況下都會**在產生 30 天後自動刪除**。申訴紀錄本身 — 包含理由、決定與已儲存的簽名 — 則不設時間限制，會在 PDF 消失之後繼續保留，直到賽事被刪除為止。
- **提交文件**（大會報名表、肖像權同意書、責任免除同意書，以及提交至賽事的醫療診斷書） — 作為賽事的一部分保留，並在**賽事結束 15 天後自動刪除**。您儲存於本人個人資料中的醫療診斷書會在其一年的有效期間內保留，並可隨時撤回。
- **OneSignal Subscription ID** — 在您登出本應用程式時、另一個帳戶在同一裝置上登入時，或 OneSignal 下次回報該訂閱已無法送達時（例如本應用程式被解除安裝或通知權限被撤銷之後）清除。在此之前，該識別碼仍會儲存在您的個人資料中。
- **本機儲存的憑證**（Remember email / Remember password） — 保留在您的裝置上，直到您停用該選項、登出或解除安裝本應用程式。
- **離線緩衝的結果** — 僅保留在裝置記憶體中；在網路恢復後數秒內同步到我們的伺服器，或在同步前本應用程式被關閉時遺失。
- **身分驗證權杖** — 短期有效；自動重新整理或到期。

## 6. 資料安全

我們透過多層安全措施保護您的資訊：

### 傳輸與儲存

- 所有資料均透過加密的 HTTPS 連線傳輸
- 資料由我們的基礎架構供應商（Supabase）於靜態加密
- 密碼使用業界標準演算法進行雜湊處理；我們絕不儲存明文密碼

### 資料庫層級存取控制

- 在包含使用者或賽事資料的所有資料表上，於資料庫層級強制執行 **Row-Level Security（RLS）**
- 使用者只能存取其所屬賽事的資料
- 待核准或未核准的成員無法存取賽事資料
- 權限在每次查詢時都會檢查，而不僅是在登入時

### 角色式權限

- **Organizer / Main Judge** — 可管理賽事、成員與比賽資料；查看活動紀錄；審核已提交文件；記錄黑視後續判斷；傳送手動推播通知。Organizer 可以 **Observer** 身分加入，此身分會將其從賽事成員清單中隱藏，但仍授予相同權限。
- **Judge** — 可查看與提交比賽成績、設定風險標記，以及查看申訴
- **Safety** — 可查看賽事資料並設定風險標記
- **Photo** — 可查看 Start List，並記錄其被指派拍攝的運動員
- **Staff** — 可查看賽事資料
- **Athlete** — 對 Start List、其本人的比賽成績、其本人已提交的文件，以及與其相關的申訴之唯讀存取
- 權限按賽事範圍隔離；某一賽事中的裁判無權存取另一賽事

### AIDA API 權杖保護

- 用於與 AIDA International 同步的 AIDA API 權杖，保存在一個獨立且已鎖定的資料庫資料表中，任何應用程式角色皆無法直接讀取或寫入：所有存取預設一律拒絕，僅能透過受限的伺服器端函式取得。它們與所有其他資料一樣，由我們的基礎架構供應商於靜態加密。
- 只有 main_judge 與 organizer 角色才能擷取權杖，並透過受限的資料庫函式強制執行
- 其他角色（judge、staff、athlete）即使有權存取其他賽事資料，也無法存取權杖
- 權杖在使用者介面中被遮蔽；使用者必須明確選擇才能顯示它們

### 工作階段與存取

- 身分驗證權杖為短期有效，並自動重新整理
- 當使用者從賽事中被移除時，存取權限會被即時撤銷
- 帳戶憑證由您負責；切勿共享它們

雖然我們採取合理措施來保護您的資訊，但沒有任何系統是完全安全的。您有責任對您的帳戶憑證保密，並回報任何可疑活動。

## 7. 兒童隱私

本應用程式旨在供參加 AIDA 認證大會的賽事主辦者、裁判、工作人員與運動員使用。帳戶適用於 16 歲及以上的使用者。若參加大會的運動員未達其所在國家的成年年齡，則依 AIDA 的大會規則，大會報名表、肖像權、責任免除與醫療文件必須由父母或法定監護人填寫並簽署；本應用程式會記錄在大會報名表上所填寫的出生日期以及所提供的簽名。未經父母同意，我們不會在知情的情況下收集 13 歲以下兒童的個人資訊。

若您認為兒童的資訊是在未取得必要同意的情況下提供的，請透過第 11 節所載的聯絡方式與我們聯繫，我們將予以刪除。
