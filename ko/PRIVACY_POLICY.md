# 개인정보처리방침

**Apnea Comp**

*최종 업데이트: 2026년 5월 9일*

---


## 1. 서론

본 개인정보처리방침은 **Apnea Comp** 모바일 애플리케이션(이하 "당사", "본 앱")이 서비스 이용 시 정보를 수집, 이용, 보호하는 방법을 설명합니다. 본 앱은 AIDA 공인 프리다이빙 대회의 운영자, 심판, 스태프, 선수를 위한 대회 관리 도구입니다.

본 앱을 사용함으로써 본 정책에 기술된 사항에 동의하게 됩니다.

---


## 2. 수집하는 정보

### 2.1 계정 정보

계정 생성 시 다음 정보를 수집합니다:

- **이메일 주소** — 인증 및 계정 복구용
- **표시 이름(닉네임)** — 다른 이벤트 참여자에게 표시
- **비밀번호** — 인증 제공자(Supabase Auth)를 통해 안전한 해시로 저장. 평문 비밀번호는 절대 저장하지 않습니다.


### 2.2 프로필 정보 (선택)

- **프로필 사진** — 업로드를 선택한 경우. 참여한 이벤트의 다른 멤버에게 표시되며, 활동 로그(2.5절)에서 참조됩니다.


### 2.3 선수 계정 연결 (선수 전용)

스타트 리스트와 본인 결과를 보기 위해 선수로 가입할 경우, 본 앱은 다음을 저장합니다:

- **AIDA 선수 UUID** — AIDA International의 영구 식별자로, 본인 계정과 이벤트 스타트 리스트의 등장 기록을 매칭하기 위해 사용됩니다. 이 UUID는 이벤트 운영자의 초대 코드 검증 또는 이름 매칭 + 승인을 거친 후에만 본인 계정에 연결됩니다.
- **동기화된 표시 이름** — AIDA 스타트 리스트에 게재된 본인의 이름과 성. 연결 단계에서 프로필로 복사됩니다.


이 정보는 본인 프로필에만 저장되며, 참여 이벤트의 읽기 전용 접근을 위해 사용됩니다.

### 2.4 선수 대회 데이터 (AIDA에서 로드)

이벤트 운영자가 AIDA International로부터 이벤트를 로드할 때 본 앱은 다음을 저장합니다:

- **선수 이름** (성 및 이름)
- **성별**
- **국적**
- **종목** (STA, DYN, CWT 등)
- **공시 기록 (AP)**
- **개인 최고 기록 (PB)**
- **대회 결과** (RP, 심판 카드, 페널티 사유, REMARKS)
- **체크인 상태** — 선수가 이벤트에 출석했는지 여부의 boolean 값. 본 앱은 체크인 시 서명 패드를 표시하여 선수의 출석을 확인할 수 있도록 하지만, **서명 이미지 자체는 저장되지 않으며**, 서명이 발생했다는 사실만 기록됩니다.


이 정보는 체크인 상태(앱 내에서 직접 기록)를 제외하고 **AIDA International의 공개 대회 기록**을 공식 API로 통해 가져옵니다.

### 2.5 수집하지 않는 정보

본 앱은 다음 정보를 명시적으로 수집하거나 저장하지 **않습니다**:

- 선수의 이메일 주소 (선수 본인이 계정을 가진 경우의 본인 이메일은 제외)
- 선수의 전화번호
- 선수의 실제 주소
- 선수의 생년월일
- 선수의 사진이나 얼굴 이미지
- 체크인 서명 이미지 (boolean 값만 저장)
- 사용자의 위치 정보
- 추적용 디바이스 식별자
- 브라우징 히스토리
- 디바이스의 연락처


### 2.6 활동 로그

대회 운영의 투명성을 위해 본 앱은 이벤트 내 주요 작업을 기록합니다:

- **로그 대상** — 심판 결과 입력, 일정 조정 (OT 지연), 체크인 작업, 멤버 역할 변경
- **각 로그 항목의 내용** — 사용자 표시 이름, 프로필 사진 URL (있는 경우), 작업 유형, 영향받은 선수 이름 (해당 시), 타임스탬프
- **공개 범위** — 동일 이벤트의 운영자(Organizer)와 메인 심판(Main Judge)만 열람 가능
- **보존 기간** — 로그 항목은 이벤트에 종속되며, 이벤트 삭제 시 함께 삭제


활동 로그는 위에 기술된 사항 외 어떠한 데이터도 포함하지 않습니다.

### 2.7 푸시 알림 데이터

이벤트 관련 알림을 디바이스에 전달하기 위해 본 앱은 다음을 저장합니다:

- **OneSignal Subscription ID** — 푸시 알림 제공자(OneSignal)가 발급한 디바이스 고유 식별자. 알림 도착지 주소로만 사용됩니다.
- **OneSignal 외부 사용자 ID** — 본인의 계정 ID로, Subscription ID와 연결되어 디바이스에 관계없이 본인 계정으로 알림이 전달될 수 있도록 합니다.
- **Subscription 타임스탬프** — 마지막 업데이트 시각. 오래된 Subscription을 감지하는 데 사용됩니다.


이 값들은 본인 계정 프로필에 저장됩니다. 알림 비활성화, 앱 삭제, 또는 디바이스의 알림 권한 취소 시 Subscription ID는 자동으로 삭제됩니다.

**참고:** Apnea Comp는 이전에 Firebase Cloud Messaging(FCM)을 푸시 전달에 사용했습니다. 2026년 5월부로 푸시 알림 인프라가 OneSignal로 이전되었습니다. 관련 제3자 제공자에 대한 자세한 내용은 4.3절을 참조하세요.

### 2.8 로컬 디바이스 저장 (오프라인 버퍼링)

수영장과 깊이 대회장에서 흔한 인터넷 연결 단절 상황에서도 운영을 지속할 수 있도록, 본 앱은 심판 결과를 서버에 도달하기 전 디바이스 메모리에 일시적으로 보관할 수 있습니다:

- **위치** — 앱이 실행되는 동안 앱 메모리에만 저장됩니다. 영구적인 디바이스 저장 공간에는 오프라인 데이터를 기록하지 않습니다.
- **시점** — 오프라인 상태에서 심판 저장이 시도될 때 자동으로
- **기간** — 본 앱이 결과를 서버와 동기화할 때까지. 인터넷이 복구되면 수 초 내에 자동 동기화됩니다.
- **공개 범위** — 오프라인 버퍼링된 결과는 동기화 성공까지 해당 디바이스에서만 보입니다. 같은 이벤트의 다른 디바이스에서는 보이지 않습니다.
- **제한 사항** — 동기화 완료 전 앱이 강제 종료되거나 디바이스가 재부팅되면 오프라인 버퍼링된 결과는 손실됩니다. 본 앱은 영향받은 항목에 "⛔ Offline" 배지를 표시하고, 동기화 대기 중인 항목이 있을 때 앱 종료를 경고합니다.


이 버퍼링은 어떠한 제3자에게도 데이터를 전송하지 않습니다.

## 3. 정보 이용 방법

수집한 정보는 다음 목적으로 사용됩니다:

- 사용자 인증 및 계정 관리
- 권한 있는 이벤트 스태프에게 대회 일정 및 선수 정보 표시
- 계정을 연결한 선수에게 스타트 리스트 및 본인 결과 표시
- 심판 결과를 AIDA International에 제출 (이벤트 운영자가 설정 시)
- 이벤트 스태프 디바이스 간 실시간 데이터 동기화
- 이벤트 내 운영 투명성을 위한 활동 로그 유지
- OneSignal을 통한 푸시 알림 전송:
  * **수동 알림** — 이벤트 운영자가 트리거 (스타트 리스트 발행, 비공식 결과, 공식 결과)
  * **자동 알림** — 이벤트 상태에 의해 트리거 (특정 선수에게 영향을 주는 일정 변경 / OT 지연, 미체크인 선수에게 보내는 체크인 마감 알림)


본 앱은 사용자 정보를 광고, 마케팅, 또는 제3자 판매에 **사용하지 않습니다**.

## 4. 데이터 공유

### 4.1 AIDA International과의 공유

이벤트 운영자가 본인의 API 토큰으로 AIDA 통합을 설정한 경우:

- AIDA International로부터 이벤트 일정, 스타트 리스트, 선수 정보를 **읽어옵니다**
- 심판 결과(선수 기록, 카드, 페널티, REMARKS)를 AIDA International로 **제출합니다**


이러한 공유는 본 앱의 핵심 기능에 필수적이며, 이벤트 운영자가 시작합니다.

### 4.2 이벤트 내 공유

이벤트 참여자(운영자, 메인 심판, 심판, 스태프)는 다음을 볼 수 있습니다:

- 같은 이벤트 다른 참여자의 이름, 프로필 사진, 역할
- 해당 이벤트의 선수 정보
- 심판 결과의 실시간 업데이트
- 활동 로그 (운영자와 메인 심판만)


계정을 연결한 선수는 다음을 볼 수 있습니다:

- 본인이 등장하는 이벤트의 스타트 리스트
- 본인의 대회 결과


정보는 이벤트 단위로 분리되어 있어, 한 이벤트의 사용자가 자신이 속하지 않은 다른 이벤트의 데이터를 볼 수 없습니다. 선수는 다른 선수의 개인 계정 정보를 볼 수 없습니다.

### 4.3 제3자 서비스 제공자

본 앱 운영을 위해 다음 서비스 제공자를 사용합니다:

- **Supabase** ([supabase.com](https://supabase.com)) — 백엔드 인증, 데이터베이스, 실시간 동기화, 프로필 사진 저장
- **OneSignal** ([onesignal.com](https://onesignal.com)) — 모바일 디바이스로의 푸시 알림 전달. 알림 전송 시 도착지 Subscription ID, 알림 제목, 알림 본문이 OneSignal 인프라를 통과합니다. OneSignal은 또한 전달 최적화를 위해 디바이스 수준 메타데이터(디바이스 모델, OS 버전, 언어, 시간대, 국가, IP 주소)를 수집할 수 있습니다. OneSignal의 개인정보처리방침은 [onesignal.com/privacy](https://onesignal.com/privacy_policy)에서 확인할 수 있습니다. OneSignal은 다시 알림 페이로드를 플랫폼 수준 푸시 서비스 — iOS의 Apple Push Notification service(APNs)와 Android의 Firebase Cloud Messaging(FCM) — 으로 전달하여 디바이스에 최종 도달시킵니다.
- **AIDA International** ([aidainternational.org](https://www.aidainternational.org)) — 공식 대회 데이터 출처
- **Apple App Store**와 **Google Play Services** — 앱 배포 및 충돌 보고


이러한 제공자는 본 앱을 대신하여 데이터를 처리하며, 자체 개인정보처리방침의 적용을 받습니다.

### 4.4 법적 요구

법률, 법원 명령, 또는 사용자의 권리·재산·안전을 보호하기 위해 필요한 경우 정보를 공개할 수 있습니다.

## 5. 데이터 보존

- **계정 데이터** — 계정이 존재하는 동안 보존. 언제든지 삭제 요청이 가능합니다 (8절 참조).
- **이벤트 데이터** (선수, 결과, 로그, 체크인 상태) — 이벤트 운영자가 이벤트를 삭제하면 자동으로 삭제됩니다.
- **OneSignal Subscription ID** — 알림 비활성화, 앱 삭제, 또는 디바이스의 알림 권한 취소 시 자동으로 삭제됩니다. 반복적으로 실패하는 Subscription(예: 디바이스가 더 이상 도달 불가)도 OneSignal에 의해 자동으로 정리됩니다.
- **오프라인 버퍼링된 결과** — 디바이스 메모리에만 보관됩니다. 인터넷 복구 후 수 초 내 서버와 동기화되거나, 동기화 전 앱이 닫히면 손실됩니다.
- **인증 토큰** — 단기 유효; 자동으로 갱신되거나 만료됩니다.

## 6. 데이터 보안

여러 계층의 보안으로 정보를 보호합니다:

### 전송 및 저장

- 모든 데이터는 암호화된 HTTPS 연결로 전송됩니다
- 데이터는 인프라 제공자(Supabase)에 의해 저장 시 암호화됩니다
- 비밀번호는 업계 표준 알고리즘으로 해시 처리되며, 평문 비밀번호는 저장되지 않습니다


### 데이터베이스 수준 접근 제어

- 사용자 또는 이벤트 데이터를 포함한 모든 테이블에 **Row-Level Security(RLS)**가 데이터베이스 수준에서 적용됩니다
- 사용자는 자신이 속한 이벤트의 데이터만 접근할 수 있습니다
- 대기 중이거나 미승인 멤버는 이벤트 데이터에 접근할 수 없습니다
- 권한은 로그인 시뿐 아니라 모든 쿼리마다 검증됩니다


### 역할 기반 권한

- **메인 심판 / 운영자** — 이벤트, 멤버, 대회 데이터 관리; 활동 로그 열람; 수동 푸시 알림 전송
- **심판** — 대회 결과 열람 및 제출
- **스태프** — 이벤트 데이터 열람
- **선수** — 스타트 리스트 및 본인 결과 읽기 전용 접근
- 권한은 이벤트 단위로 분리됩니다. 한 이벤트의 심판은 다른 이벤트에 대한 접근 권한이 없습니다.


### AIDA API 토큰 보호

- AIDA API 토큰(AIDA International과의 동기화에 사용)은 데이터베이스에 암호화되어 저장됩니다
- main_judge와 organizer 역할만 토큰을 가져올 수 있으며, 제한된 데이터베이스 함수를 통해 시행됩니다
- 다른 역할(judge, staff, athlete)은 다른 이벤트 데이터에는 접근 가능하더라도 토큰에는 접근할 수 없습니다
- 토큰은 사용자 인터페이스에서 마스킹되며, 사용자가 명시적으로 보기를 선택해야만 표시됩니다


### 세션 및 접근

- 인증 토큰은 단기 유효하며 자동으로 갱신됩니다
- 사용자가 이벤트에서 제거되면 접근이 실시간으로 취소됩니다
- 계정 자격 증명은 사용자의 책임이며, 절대 공유해서는 안 됩니다

## 9. 국제 데이터 이전

본 앱은 서비스 제공자가 운영하는 지역에서 데이터를 처리하고 저장할 수 있습니다. Supabase 데이터는 현재 미국에 저장됩니다. 푸시 알림은 OneSignal을 통해 전달되며, OneSignal은 글로벌하게 운영되고 미국 등 인프라가 위치한 지역에서 알림 메타데이터를 처리할 수 있습니다. OneSignal은 다시 알림을 Apple Push Notification service(APNs)와 Firebase Cloud Messaging(FCM)을 통해 전달하며, 이들 또한 글로벌하게 운영됩니다. 본 앱을 사용함으로써 이러한 지역으로의 데이터 이전 및 처리에 동의하게 됩니다.
