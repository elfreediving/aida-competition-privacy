# 개인정보 처리방침

**Apnea Comp**

*최종 업데이트: 2026년 6월 2일*

---


## 1. 서론

본 개인정보 처리방침은 **Apnea Comp** 모바일 애플리케이션(이하 “당사”, “본 앱”)이 서비스 이용 시 정보를 수집·이용·보호하는 방법을 설명합니다. 본 앱은 AIDA 공인 프리다이빙 대회의 운영진(organizer), 심판(judge), 스태프(staff), 선수(athlete)를 위한 대회 관리 도구입니다.

본 앱을 이용함으로써 본 방침에 명시된 처리 방식에 동의하는 것으로 간주됩니다.

---


## 2. 수집하는 정보

### 2.1 계정 정보

계정을 생성할 때 다음 정보를 수집합니다.

- **이메일 주소** — 인증 및 계정 복구용
- **표시 이름(Display name)** — 같은 이벤트 참가자에게 표시됨
- **비밀번호** — 인증 제공자(Supabase Auth)를 통해 안전한 해시 형태로 저장됨. 평문으로 저장하지 않음


### 2.2 프로필 정보 (선택)

- **프로필 사진** — 업로드를 선택한 경우 저장. 사용자가 참여하는 이벤트의 다른 멤버에게 노출되며 활동 로그(2.6항 참고)에서도 참조됨


### 2.3 선수 계정 연동 (선수 사용자만 해당)

선수로 가입하여 Start List 및 본인 결과를 조회하기 위해 다음 정보를 저장합니다.

- **AIDA 선수 UUID** — AIDA International에서 부여하는 영구 식별자. 이벤트의 Start List 내에서 본인을 매칭하기 위해 사용. 이벤트 운영자의 초대 코드 확인 또는 Start List에서 이름 매칭 후 승인이 완료된 시점부터만 본인 계정에 연동됨
- **동기화된 표시 이름** — AIDA Start List에 게시된 이름(First/Last name)이 연동 단계에서 본인 프로필로 복사됨
- **AIDA 검색어** — “Find me on AIDA” 기능으로 본인 선수 프로필을 찾을 때, 입력한 이름이 AIDA International의 공개 선수 검색 서비스로 전송되어 일치하는 프로필을 조회함. 입력한 검색어만 전송되며 계정 자격 정보는 포함되지 않음(4.1항 참고)


이 데이터는 본인 프로필에만 보관되며, 참여하는 이벤트의 읽기 전용 접근 권한 부여 목적으로만 사용됩니다.

### 2.4 선수 경기 데이터 (AIDA에서 불러옴)

이벤트 운영자가 AIDA International로부터 이벤트를 불러올 때, 본 앱은 다음 정보를 저장합니다.

- **선수 이름** (First/Last name)
- **성별**
- **국적**
- **종목** (STA, DYN, CWT 등)
- **공식 신청 기록(Announced Performance, AP)**
- **개인 최고 기록(Personal Best, PB)**
- **경기 결과** (RP, 판정 카드, 페널티 사유, REMARKS)
- **포인트(Points)** — 결과로부터 계산된 대회 포인트
- **엔트리 유형(Entry type)** — 일반 출전(regular), *opener*(순위·AIDA 제외 워밍업 엔트리), *재경기(re-swim)*(이의제기로 승인된 재시기) 구분
- **유효성 플래그** — 선수가 재경기하면 원본 엔트리는 *invalidated*로 표시되어 순위에서 제외됨(단, Results에는 계속 표시됨)
- **체크인 상태** — 선수가 이벤트 현장에서 출석 확인을 완료했는지 여부의 불리언 플래그. 본 앱은 체크인 시 서명 패드를 표시하여 선수가 출석을 확인할 수 있도록 하지만, **서명 이미지 자체는 저장되지 않음** — 서명이 이루어졌다는 사실(불리언)만 저장됨


위 정보는 체크인 상태를 제외하고 **AIDA International의 공개 대회 기록**(공식 API 경유)에서 가져온 것입니다. 체크인 상태는 본 앱에서 직접 기록됩니다.

### 2.5 수집하지 않는 정보

당사는 다음 정보를 수집·저장하지 **않습니다**.

- 선수의 이메일 주소(선수 본인이 계정을 가진 경우 본인 이메일 제외)
- 선수의 전화번호
- 선수의 실제 주소
- 선수의 생년월일
- 선수의 사진 또는 얼굴 이미지
- 체크인 서명 이미지(불리언 플래그만 저장)
- 사용자의 위치 데이터
- 추적용 디바이스 식별자
- 브라우징 이력
- 기기의 연락처


### 2.6 활동 로그

대회 운영의 투명성을 위해, 본 앱은 이벤트 내에서 발생한 주요 동작을 기록합니다.

- **로그 대상** — 심판의 결과 기록, 일정 조정(OT Delay), 체크인 작업, 멤버 역할 변경
- **각 로그 항목 구성** — 사용자의 표시 이름, 프로필 사진 URL(설정된 경우), 동작 유형, 영향을 받은 선수 이름(해당되는 경우), 타임스탬프
- **공개 범위** — 같은 이벤트의 Organizer 및 Main Judge에게만 보임
- **보관 기간** — 이벤트에 종속되며, 이벤트 삭제 시 함께 삭제됨


활동 로그에는 위 명시된 데이터 외 어떠한 추가 정보도 포함되지 않습니다.

### 2.7 푸시 알림 데이터

이벤트 관련 알림을 사용자 기기로 전달하기 위해 본 앱은 다음을 저장합니다.

- **OneSignal Subscription ID** — 푸시 알림 제공자(OneSignal)가 발급하는 디바이스별 식별자. 알림 전송의 목적지 주소로만 사용됨
- **OneSignal external user ID** — 사용자의 계정 ID로, Subscription ID와 연결되어 디바이스가 바뀌어도 계정 단위로 알림 발송 가능
- **Subscription 타임스탬프** — 마지막 갱신 시각. 만료된 구독을 감지하는 데 사용


이 값들은 사용자의 계정 프로필에 저장됩니다. Subscription ID는 알림이 비활성화되거나, 앱이 삭제되거나, 기기의 알림 권한이 해제되면 자동으로 삭제됩니다.

**참고:** Apnea Comp는 이전에 Firebase Cloud Messaging(FCM)을 푸시 전송 인프라로 사용했습니다. 2026년 5월부터는 OneSignal로 마이그레이션되었습니다. 관련 제3자 제공자 세부 사항은 4.3항 참고.

### 2.8 기기 로컬 저장소

본 앱은 두 가지 목적으로 사용자 기기에 제한된 데이터를 저장합니다.

**오프라인 버퍼링 (Judge 결과)**

수영장·다이브 현장에서는 인터넷이 간헐적으로 끊길 수 있어, 본 앱은 심판 결과를 서버에 전송하기 전 일시적으로 기기 메모리에 보관할 수 있습니다.

- **저장 위치** — 앱 실행 중인 메모리에만 저장됨. 오프라인 버퍼링된 심판 결과는 기기의 영구 저장소에 기록되지 않음
- **저장 시점** — 오프라인 상태에서 심판이 결과를 저장하려고 할 때 자동으로 처리됨
- **보관 기간** — 인터넷이 복구된 후 수 초 내 자동 동기화 시까지
- **공개 범위** — 동기화 완료 전까지는 결과를 생성한 기기에서만 보임. 같은 이벤트의 다른 기기에는 표시되지 않음
- **제약** — 동기화 완료 전에 앱이 강제 종료되거나 기기가 재부팅되면 오프라인 버퍼링된 결과는 손실됨. 본 앱은 해당 항목에 “⛔ Offline” 배지를 표시하고 동기화 미완료 항목이 있을 때 앱 종료를 피하도록 안내함

**자동 로그인 편의 (Remember Email / Password)**

로그인 화면에는 다음 로그인 시 자동 입력되도록 자격 정보를 기기에 로컬 저장하는 두 가지 선택 토글이 있습니다.

- **Remember email** — 활성화 시 이메일 주소를 기기 일반 로컬 저장소(Android의 SharedPreferences, iOS의 NSUserDefaults)에 저장
- **Remember password** — 활성화 시 비밀번호를 기기 **보안 키 저장소**(iOS Keychain / Android EncryptedSharedPreferences, AES-256, 운영체제 암호화)에 저장. 평문으로 저장되지 않으며 당사 서버나 제3자에게 전송되지 않음. 같은 기기에서 로그인 폼 자동 입력 및 세션 복원 용도로만 사용됨
- **저장 위치** — 사용자 기기 내에만 저장. 당사 서버 또는 제3자에게 전송되지 않음
- **삭제 방법** — 다음 로그인 시 해당 옵션 체크 해제, 또는 앱 로그아웃(저장된 자격 정보 함께 삭제됨), 또는 앱 삭제

**표시 환경설정(Display Preferences)**

테마 선택(라이트 / 다크 / 시스템)과 앱 언어는 앱 재실행 시에도 유지되도록 로컬(SharedPreferences)에 저장됩니다. 이는 환경설정값일 뿐이며 개인정보를 포함하지 않습니다.

오프라인 버퍼링, 자동 로그인 편의, 표시 환경설정 저장 모두 제3자에게 데이터를 전송하지 않습니다.

### 2.9 이의제기(Protest) 데이터

AIDA 대회 규정(룰북 17.7)에 따라 이의제기가 제출되면, 본 앱은 다음을 포함하는 protest 레코드를 저장합니다.

- **이의제기 사유** — 제출자가 입력한 자유 텍스트
- **선수 서명** 및 (해당 시) **Jury 서명** — 손으로 그린 이미지로 캡처되어 protest 레코드에 base64로 저장됨. 체크인 서명 패드와 달리, 서명된 이의제기는 공식 대회 기록의 일부이므로 **protest 서명은 보관됨**
- **생성된 이의제기 양식** — 사유와 서명이 포함된 PDF로, 당사 백엔드 파일 스토리지(Supabase Storage)에 저장됨
- **결정 및 수정 내용** — jury의 결정(accepted / rejected / withdrawn) 및, accept된 경우 수정된 결과(card, RP, remarks)

**공개 범위** — protest 레코드는 해당 이벤트의 스태프(Organizer, Main Judge, Judge)와 이의제기 대상 선수에게 보입니다. 이의제기 활동은 푸시 알림을 발생시킵니다(3항 참고).

## 3. 정보 이용

수집된 정보는 다음 목적으로 이용됩니다.

- 사용자 인증 및 계정 관리
- 권한이 부여된 이벤트 스태프에게 대회 일정 및 선수 정보 제공
- 연동된 계정의 선수에게 Start List 및 본인 결과 제공
- 이벤트 운영자가 설정한 경우 AIDA International에 심판 결과 제출
- 이벤트 스태프의 여러 기기 간 실시간 데이터 동기화
- 이벤트 내 운영 투명성을 위한 활동 로그 유지
- AIDA 대회 규정에 따른 이의제기 관리 — 서명 캡처 및 jury 결정·수정 결과 기록 포함
- 업데이트 안내를 위해 서버측 최소 지원 앱 빌드(공개 설정값) 확인 — 이 확인은 어떠한 개인정보도 전송하지 않음
- OneSignal을 통한 푸시 알림 발송:
  * **수동 알림** — 이벤트 운영자가 발송하는 알림 (Start List 게시, 비공식 결과, 공식 결과)
  * **자동 알림** — 이벤트 상태에 따라 발송 (일정 변경/OT Delay 영향 선수 대상; 체크인 미완료 선수 대상 체크인 마감 알림; 이의제기 활동 — 제출, 선수 서명 대기, 결정)
  * 알림 텍스트는 수신자의 앱 언어로 현지화됨


당사는 사용자의 정보를 광고, 마케팅, 제3자 판매 목적으로 이용하지 **않습니다**.

## 4. 정보 공유

### 4.1 AIDA International과의 공유

이벤트 운영자가 AIDA API 토큰을 설정하여 AIDA 연동을 구성한 경우:

- AIDA International로부터 이벤트 일정, Start List, 선수 정보를 **읽어옴**
- AIDA International로 심판 결과(선수 기록, 카드, 페널티, REMARKS)를 **제출함**


이 공유는 본 앱의 핵심 기능에 필수적이며 이벤트 운영자에 의해 개시됩니다.

별도로, 선수가 **“Find me on AIDA”** 기능을 사용하면 입력한 이름 텍스트가 AIDA International의 공개 선수 검색 서비스로 전송되어 일치하는 선수 프로필을 조회합니다. 검색어만 전송되며 계정 자격 정보나 기타 개인정보는 포함되지 않습니다.

### 4.2 이벤트 내부

이벤트 참가자(organizer, main judge, judge, staff)는 다음을 볼 수 있습니다.

- 같은 이벤트의 다른 참가자의 이름, 프로필 사진, 역할
- 해당 이벤트의 선수 정보
- 심판 결과의 실시간 업데이트
- 활동 로그 (Organizer 및 Main Judge에게만)


연동된 계정의 선수는 다음을 볼 수 있습니다.

- 본인이 등록된 이벤트의 Start List
- 본인의 경기 결과


정보는 이벤트 단위로 격리됩니다 — 한 이벤트의 사용자는 자신이 속하지 않은 다른 이벤트의 데이터를 볼 수 없습니다. 선수는 다른 선수의 개인 계정 정보를 볼 수 없습니다.

### 4.3 제3자 서비스 제공자

본 앱은 다음 서비스 제공자를 이용합니다.

- **Supabase** ([supabase.com](https://supabase.com)) — 백엔드 인증, 데이터베이스, 실시간 동기화, 파일 저장(프로필 사진 및 생성된 이의제기 양식 PDF)
- **OneSignal** ([onesignal.com](https://onesignal.com)) — 모바일 기기로의 푸시 알림 전송. 알림이 발송될 때 대상 Subscription ID, 알림 제목, 알림 본문이 OneSignal 인프라를 거쳐 전달됨. OneSignal은 전송 최적화를 위해 디바이스 수준 메타데이터(디바이스 모델, OS 버전, 언어, 시간대, 국가, IP 주소)를 수집할 수 있음. OneSignal의 개인정보 처리방침: [onesignal.com/privacy](https://onesignal.com/privacy_policy). OneSignal은 다시 플랫폼별 푸시 서비스 — iOS의 Apple Push Notification service(APNs), Android의 Firebase Cloud Messaging(FCM) — 로 알림 페이로드를 전달하여 기기까지의 최종 전송을 수행함
- **AIDA International** ([aidainternational.org](https://www.aidainternational.org)) — 공식 대회 데이터 제공원
- **Apple App Store** 및 **Google Play Services** — 앱 배포 및 충돌 보고

- **OneSignal Subscription ID** — 알림을 비활성화하거나, 앱을 삭제하거나, 기기의 알림 권한을 해제하면 자동 삭제. 반복적으로 전송 실패한 구독(예: 기기 도달 불가)도 OneSignal에 의해 자동 삭제됨

- **오프라인 버퍼링된 결과** — 기기 메모리에만 보관. 인터넷 복구 후 수 초 내 동기화되거나, 동기화 전 앱이 종료되면 소실

## 6. 데이터 보안

당사는 다음 다층 보안으로 정보를 보호합니다.

### 전송 및 저장

- 모든 데이터는 암호화된 HTTPS 연결로 전송됨
- 데이터는 인프라 제공자(Supabase)에 의해 저장 시 암호화됨
- 비밀번호는 업계 표준 알고리즘으로 해시되며, 평문 비밀번호는 절대 저장되지 않음


### 데이터베이스 수준 접근 통제

- 사용자 및 이벤트 데이터를 포함하는 모든 테이블에 **Row-Level Security(RLS)** 가 적용됨
- 사용자는 본인이 속한 이벤트의 데이터에만 접근 가능
- 승인 대기 또는 미승인 멤버는 이벤트 데이터에 접근 불가
- 로그인 시점이 아닌 모든 쿼리에서 권한이 검증됨


### 역할 기반 권한

- **Main Judge / Organizer** — 이벤트, 멤버, 대회 데이터 관리; 활동 로그 조회; 수동 푸시 알림 발송 가능
- **Judge** — 대회 결과 조회 및 입력 가능
- **Staff** — 이벤트 데이터 조회 가능
- **Athlete** — Start List 및 본인 결과 읽기 전용 접근
- 권한은 이벤트 단위로 격리되며, 한 이벤트의 심판은 다른 이벤트에 대한 접근 권한이 없음


### AIDA API 토큰 보호

- AIDA International 연동에 사용되는 AIDA API 토큰은 데이터베이스에 암호화 저장됨
- 제한된 데이터베이스 함수를 통해 main_judge 및 organizer 역할만 토큰을 가져올 수 있음
- 다른 역할(judge, staff, athlete)은 이벤트의 다른 데이터에 접근 가능하더라도 토큰에 접근할 수 없음
- 사용자 인터페이스에서 토큰은 마스킹되며, 사용자가 명시적으로 표시 옵션을 선택해야만 보임


### 세션 및 접근

- 인증 토큰은 단기 토큰이며 자동으로 갱신됨
- 이벤트에서 제거되면 접근 권한이 실시간으로 회수됨
- 계정 자격 정보는 사용자의 책임이며, 절대 공유하지 마십시오


당사는 합리적인 정보 보호 조치를 취하지만, 어떤 시스템도 완전히 안전할 수는 없습니다. 사용자는 본인의 계정 자격 정보를 비밀로 유지하고 의심스러운 활동을 신고할 책임이 있습니다.

## 9. 국가 간 데이터 이전

본 앱은 서비스 제공자가 운영하는 지역에서 데이터를 처리·저장할 수 있습니다. Supabase 데이터는 현재 미국에 저장됩니다. 푸시 알림은 OneSignal을 통해 전송되며, OneSignal은 전 세계적으로 운영되어 미국 및 기타 인프라 위치에서 알림 메타데이터를 처리할 수 있습니다. OneSignal은 다시 알림을 Apple Push Notification service(APNs) 및 Firebase Cloud Messaging(FCM)을 통해 전달하며 이들도 전 세계적으로 운영됩니다. 본 앱을 이용함으로써 사용자의 데이터가 이러한 지역으로 전송·처리되는 것에 동의하는 것으로 간주됩니다.
