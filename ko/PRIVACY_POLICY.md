# 개인정보 처리방침

**Apnea Comp**

*최종 업데이트: 2026년 9월 18일*

---


## 1. 서론

본 개인정보 처리방침은 **Apnea Comp** 모바일 애플리케이션(이하 “당사”, “본 앱”)이 서비스 이용 시 정보를 수집·이용·보호하는 방법을 설명합니다. 본 앱은 AIDA 공인 프리다이빙 대회의 운영진(organizer), 심판(judge), 스태프(staff), 선수(athlete)를 위한 대회 관리 도구입니다.

본 앱을 이용함으로써 본 방침에 명시된 처리 방식에 동의하는 것으로 간주됩니다.

---


## 2. 수집하는 정보

### 2.1 계정 정보

계정을 생성할 때 다음 정보를 수집합니다.

- **이메일 주소** — 인증 및 계정 복구용
- **표시 이름(Display name)** — 같은 이벤트 참가자에게 표시됨
- **비밀번호** — 인증 제공자(Supabase Auth)를 통해 안전한 해시 형태로 저장됨. 평문으로 저장하지 않음


**Apple 또는 Google로 로그인.** 이메일·비밀번호 로그인 대신 Apple 또는 Google 계정으로 로그인할 수 있습니다. 이 경우 당사는 계정 생성 또는 식별을 위해 Apple 또는 Google로부터 **이름**과 **이메일 주소**를 전달받습니다. **Sign in with Apple**을 사용하고 이메일 가리기를 선택하면 Apple은 실제 주소 대신 비공개 릴레이 이메일 주소를 제공하며, 당사는 이를 다른 이메일과 동일하게 사용합니다. 당사는 Apple 또는 Google 비밀번호를 전달받지 않습니다 — 로그인은 해당 제공자와 당사 인증 제공자(Supabase Auth)가 함께 처리합니다.


### 2.2 프로필 정보 (선택)

- **프로필 사진** — 업로드를 선택한 경우 저장. 사용자가 참여하는 이벤트의 다른 멤버에게 노출되며 활동 로그(2.6항 참고)에서도 참조됨


### 2.3 선수 계정 연동 (선수 사용자만 해당)

선수로 가입하여 Start List 및 본인 결과를 조회하기 위해 다음 정보를 저장합니다.

- **AIDA 선수 UUID** — AIDA International에서 부여하는 영구 식별자. 이벤트의 Start List 내에서 본인을 매칭하기 위해 사용. 이벤트 운영자의 초대 코드 확인 또는 Start List에서 이름 매칭 후 승인이 완료된 시점부터만 본인 계정에 연동됨
- **동기화된 표시 이름** — AIDA Start List에 게시된 이름(First/Last name)이 연동 단계에서 본인 프로필로 복사됨
- **AIDA 검색어** — “AIDA에서 내 이름 찾기”(Find me on AIDA) 기능으로 본인 선수 프로필을 찾을 때, 입력한 이름이 AIDA International의 공개 선수 검색 서비스로 전송되어 일치하는 프로필을 조회함. 입력한 검색어만 전송되며 계정 자격 정보는 포함되지 않음(4.1항 참고)
- **AIDA 공개 프로필 조회** — 앱에서 누군가 선수 프로필을 열면, 본 앱은 해당 선수의 AIDA UUID를 사용하여 AIDA International 웹사이트에 그 선수의 공개 프로필 페이지와 공개 결과 페이지를 요청하고, AIDA가 공개하는 커리어 기록, 국가·대륙·세계 랭킹, 대회 이력, 프로필 사진을 표시함. 계정 자격 정보는 전송되지 않으며 당사는 사본을 저장하지 않음 — 조회 결과는 현재 세션 동안 앱 메모리에만 보관되며 앱을 재시작하면 삭제됨


이 데이터는 본인 프로필에만 보관되며, 참여하는 이벤트의 읽기 전용 접근 권한 부여 목적으로만 사용됩니다.

### 2.4 선수 경기 데이터 (AIDA에서 불러옴)

이벤트 운영자가 AIDA International로부터 이벤트를 불러올 때, 본 앱은 다음 정보를 저장합니다.

- **선수 이름** (First/Last name)
- **성별**
- **국적**
- **종목** (STA, DYN, CWT 등)
- **공식 신청 기록(Announced Performance, AP)**
- **개인 최고 기록(Personal Best, PB)**
- **경기 결과** (RP, 판정 카드, 페널티 사유, REMARKS)
- **포인트(Points)** — 결과로부터 계산된 대회 포인트
- **엔트리 유형(Entry type)** — 일반 출전(regular), *opener*(순위·AIDA 제외 워밍업 엔트리), *재경기(re-swim)*(이의제기로 승인된 재시기) 구분
- **유효성 플래그** — 선수가 재경기하면 원본 엔트리는 *invalidated*로 표시되어 순위에서 제외됨(단, Results에는 계속 표시됨)
- **체크인 상태** — 선수가 대기(pending), 체크인 완료(checked in), 지각 체크인(late check-in), 불참(DNS) 중 어느 상태인지와 체크인 시각. AIDA 규정상 지각 체크인이나 DNS에는 대회 페널티가 따르며, 체크인 마감 시각이 지나면 본 앱이 선수를 자동으로 지각 처리할 수 있음. 본 앱은 체크인 시 서명 패드를 표시하여 선수가 출석을 확인할 수 있도록 하지만, **서명 이미지 자체는 저장되지 않음** — 서명이 이루어졌다는 사실만 저장됨
- **위험 마킹(Risk marking)** — 이벤트 스태프가 선수에게 설정할 수 있는 안전 표시(2.11항 참고)


위 정보는 체크인 상태와 위험 마킹을 제외하고 **AIDA International의 공개 대회 기록**(공식 API 경유)에서 가져온 것입니다. 체크인 상태와 위험 마킹은 본 앱에서 직접 기록됩니다.

### 2.5 수집하지 않는 정보

당사는 다음 정보를 수집·저장하지 **않습니다**.

- 선수의 이메일 주소 — 다만 본인 계정을 보유한 선수의 이메일 주소, 그리고 운영자에게 표시되는 이벤트 멤버의 이메일 주소는 예외
- 선수의 전화번호 — 다만 본인이 제출을 선택한 의료진술서에 기재된 의사의 연락처는 예외
- 선수의 실제 주소
- 체크인 서명 이미지(불리언 플래그만 저장)
- 사용자의 위치 데이터
- 광고 또는 앱 간 추적 식별자, 그리고 광고 목적의 데이터 이용 일체
- 브라우징 이력
- 기기의 연락처


당사는 사용자가 로그인한 기기에 대해 무작위로 생성된 식별자를 저장합니다. 이 식별자는 본 앱이 생성하며 어떠한 하드웨어 식별자에서도 파생되지 않고, 하나의 계정이 한 번에 하나의 기기에서만 로그인되도록 강제하고 이벤트 진행 중 Speaker Mode 기기의 로그인을 유지하는 용도로만 사용됩니다.

당사는 선수의 얼굴 사진을 저장하지 않습니다. 본인이 직접 업로드한 프로필 사진은 저장되며(2.2항), AIDA International이 공개한 선수 프로필 사진은 프로필을 열 때 AIDA의 공개 웹사이트에서 불러와 본 앱에 표시됩니다(2.3항).


### 2.6 활동 로그

대회 운영의 투명성을 위해, 본 앱은 이벤트 내에서 발생한 주요 동작을 기록합니다.

- **로그 대상** — 심판의 결과 입력 및 정정, 일정 조정(OT Delay), 체크인 작업(시스템에 의한 자동 지각 처리 포함), Setup 및 Start List 변경, 알림 발송 및 취소, 멤버 역할 변경, 그리고 선수의 의료진술서에 대해 취한 조치(무효화, 복구, 체크인 시 과거 블랙아웃 확인)
- **각 로그 항목 구성** — 사용자의 표시 이름, 프로필 사진 URL(설정된 경우), 동작 유형, 영향을 받은 선수 이름(해당되는 경우), 타임스탬프, 그리고 무엇이 변경되었는지 기술한 구조화된 상세 기록(예: 결과의 변경 전·후 값)
- **별도의 판정 감사 기록** — 저장된 심판 결과에 대한 모든 변경은, 서버가 차단한 시도까지 포함하여, 조치한 사용자의 이메일 주소와 변경 전·후 값을 담은 별도의 감사 테이블에 추가로 기록됨. 이는 분쟁이 발생한 결과를 재구성할 수 있도록 하기 위한 것임. 이 기록은 해당 이벤트의 Organizer와 Main Judge만 읽을 수 있으며 앱 내 화면은 없음
- **공개 범위** — 활동 로그 화면은 Organizer와 Main Judge에게 제공됨. 로그 항목은 이벤트 내부에 저장되며, 기술적으로는 같은 이벤트의 승인된 멤버가 당사 API를 통해 읽을 수 있음
- **보관 기간** — 로그 항목과 판정 감사 기록은 이벤트 레코드가 존재하는 동안 보관됨. 데이터베이스 제약으로 이벤트에 연결되어 있지 않기 때문에 이벤트를 삭제해도 자동으로 제거되지 않음(5항 참고)


### 2.7 푸시 알림 데이터

이벤트 관련 알림을 사용자 기기로 전달하기 위해 본 앱은 다음을 저장합니다.

- **OneSignal Subscription ID** — 푸시 알림 제공자(OneSignal)가 발급하는 디바이스별 식별자. 알림 전송의 목적지 주소로만 사용됨
- **OneSignal external user ID** — 사용자의 계정 ID로, Subscription ID와 연결되어 디바이스가 바뀌어도 계정 단위로 알림 발송 가능
- **Subscription 타임스탬프** — 마지막 갱신 시각. 만료된 구독을 감지하는 데 사용


이 값들은 사용자의 계정 프로필에 저장됩니다. Subscription ID는 앱에서 로그아웃할 때, 같은 기기에서 다른 계정이 로그인할 때, 그리고 OneSignal이 해당 구독이 더 이상 유효하지 않다고 보고할 때(예: 앱 삭제 또는 알림 권한 해제 이후) 자동으로 삭제됩니다.

**참고:** Apnea Comp는 이전에 Firebase Cloud Messaging(FCM)을 푸시 전송 인프라로 사용했습니다. 2026년 5월부터는 OneSignal로 마이그레이션되었습니다. 관련 제3자 제공자 세부 사항은 4.3항 참고.

### 2.8 기기 로컬 저장소

본 앱은 두 가지 목적으로 사용자 기기에 제한된 데이터를 저장합니다.

**오프라인 버퍼링 (Judge 결과)**

수영장·다이브 현장에서는 인터넷이 간헐적으로 끊길 수 있어, 본 앱은 심판 결과를 서버에 전송하기 전 일시적으로 기기 메모리에 보관할 수 있습니다.

- **저장 위치** — 앱 실행 중인 메모리에만 저장됨. 오프라인 버퍼링된 심판 결과는 기기의 영구 저장소에 기록되지 않음
- **저장 시점** — 오프라인 상태에서 심판이 결과를 저장하려고 할 때 자동으로 처리됨
- **보관 기간** — 인터넷이 복구된 후 수 초 내 자동 동기화 시까지
- **공개 범위** — 동기화 완료 전까지는 결과를 생성한 기기에서만 보임. 같은 이벤트의 다른 기기에는 표시되지 않음
- **제약** — 동기화 완료 전에 앱이 강제 종료되거나 기기가 재부팅되면 오프라인 버퍼링된 결과는 손실됨. 본 앱은 해당 항목에 “⛔ Offline” 배지를 표시하고 동기화 미완료 항목이 있을 때 앱 종료를 피하도록 안내함

**자동 로그인 편의 (Remember Email / Password)**

로그인 화면에는 다음 로그인 시 자동 입력되도록 자격 정보를 기기에 로컬 저장하는 두 가지 선택 토글이 있습니다.

- **이메일 기억하기(Remember email)** — 활성화 시 이메일 주소를 기기 일반 로컬 저장소(Android의 SharedPreferences, iOS의 NSUserDefaults)에 저장
- **비밀번호 기억하기(Remember password)** — 활성화 시 비밀번호를 기기 **보안 키 저장소**(iOS Keychain / Android EncryptedSharedPreferences, AES-256, 운영체제 암호화)에 저장. 평문으로 저장되지 않으며 당사 서버나 제3자에게 전송되지 않음. 같은 기기에서 로그인 폼 자동 입력 및 세션 복원 용도로만 사용됨
- **저장 위치** — 사용자 기기 내에만 저장. 당사 서버 또는 제3자에게 전송되지 않음
- **삭제 방법** — 다음 로그인 시 해당 옵션 체크 해제, 또는 앱 로그아웃(저장된 자격 정보 함께 삭제됨), 또는 앱 삭제

**표시 환경설정(Display Preferences)**

테마 선택(라이트 / 다크 / 시스템)과 앱 언어는 앱 재실행 시에도 유지되도록 로컬(SharedPreferences)에 저장됩니다. 이는 환경설정값일 뿐이며 개인정보를 포함하지 않습니다.

오프라인 버퍼링, 자동 로그인 편의, 표시 환경설정 저장 모두 제3자에게 데이터를 전송하지 않습니다.

### 2.9 이의제기(Protest) 데이터

AIDA 대회 규정(룰북 17.7)에 따라 이의제기가 제출되면, 본 앱은 다음을 포함하는 protest 레코드를 저장합니다.

- **이의제기 사유** — 제출자가 입력한 자유 텍스트
- **선수 서명** 및 (해당 시) **Jury 서명** — 손으로 그린 이미지로 캡처되어 protest 레코드에 base64로 저장됨. 체크인 서명 패드와 달리, 서명된 이의제기는 공식 대회 기록의 일부이므로 **protest 서명은 보관됨**
- **생성된 이의제기 양식** — 사유와 서명이 포함된 PDF로, 당사 백엔드 파일 스토리지(Supabase Storage)에 저장됨
- **결정 및 수정 내용** — jury의 결정(accepted / rejected / withdrawn) 및, accept된 경우 수정된 결과(card, RP, remarks)

**공개 범위** — protest 레코드는 해당 이벤트의 스태프(Organizer, Main Judge, Judge)와 이의제기 대상 선수에게 보입니다. 이의제기 활동은 푸시 알림을 발생시킵니다(3항 참고).

### 2.10 제출 서류 (동의서 및 의료진술서)

선수가 이벤트에 참가할 때, 앱은 주최자가 요구하는 동의 및 자격 관련 서류를 수집하고 저장할 수 있습니다:

- **대회 참가 신청서** — 성별, 생년월일, 출생 국가, 국적, 종목별 개인 최고 기록, 그리고 **본인이 선택하여 신고하는 건강 관련 이력**(최근 압력 손상/기압 외상 일자, 최근 블랙아웃 일자, 최근 건강검진 일자).
- **초상권 동의서** 및 **책임 면제 동의서** — 본인 이름, 이벤트 이름 및 장소, 서명 일자, 그리고 손으로 직접 그린 서명.
- **의료진술서 (선택)** — 검진/발급 일자와 의사의 이름, 전화번호, 손으로 직접 그린 서명이 포함된 의사의 적합성 진단서. 본인의 건강을 증명하는 서류이므로 이는 **민감한 건강 정보**입니다. 의료진술서는 1년간 유효하며, 본인의 선택에 따라 향후 이벤트에서 재사용할 수 있도록 본인 프로필에 저장됩니다.
- **서명** — 선수, 증인, 의사의 서명은 손으로 그린 이미지로 캡처되어 생성된 서류에 삽입됩니다. 체크인 서명과 달리, 이 서명들은 동의 기록의 일부로 **보관**됩니다.
- **업로드 파일** — 앱에서 직접 작성하는 대신 서류를 사진이나 스캔본으로 제출하는 경우, 해당 이미지 파일이 저장됩니다.
- **생성된 PDF** — 앱에서 작성한 서류는 PDF로 렌더링되어 당사 백엔드 파일 저장소(Supabase Storage)에 저장됩니다.

**열람 범위** — 제출된 이벤트 서류는 검증을 위해 해당 이벤트의 Organizer와 Main Judge가 열람할 수 있으며, 이들은 서류를 ZIP 아카이브로 일괄 다운로드할 수도 있습니다. 부상 또는 블랙아웃 일자를 신고하는 경우, 스태프에게 의료진술서를 수동으로 검증하라는 안내가 표시됩니다.

**알림** — 필수 서류를 이벤트 전날까지 제출하지 않은 경우, 누락된 서류를 안내하는 푸시 알림을 받을 수 있습니다.

**보유 근거** — 의료진술서와 대회 참가 신청서에 신고한 건강 이력은 본인이 해당 양식을 작성하여 제출하기로 선택할 때 제공하는 **명시적 동의**에 근거하여 처리됩니다. 11항의 연락처로 언제든지 이 동의를 철회할 수 있으나, 그 경우 AIDA 규정상 운영자가 본인의 대회 출전을 허용하지 못할 수 있습니다.

### 2.11 이벤트 중 안전 및 의료 기록

프리다이빙 대회는 안전이 매우 중요하며, AIDA 규정은 특정 의료 사건을 기록하고 조치하도록 요구합니다. 이에 따라 본 앱은 다음을 저장합니다.

- **위험 마킹** — Organizer, Main Judge, Judge 또는 Safety 스태프가 경기 전 선수에게 설정할 수 있는 안전 표시(none / yellow / orange / red)로, 세이프티 다이버와 심판이 대비할 수 있도록 합니다. 이 표시는 앱과 연결된 Apple Watch에서 이벤트 스태프에게 보이며, 해당 선수의 이벤트 엔트리와 함께 저장됩니다.
- **블랙아웃 후속 확인 기록** — 선수에게 블랙아웃이 발생했거나 위험도가 높게 표시된 경우, Organizer 또는 Main Judge가 후속 판단(“이상 없음 — 출전 가능” 또는 “재검진 요구”), 선택 사항인 의료진 메모, 판단한 사람, 판단 시각을 기록합니다. 이 기록은 같은 이벤트의 이후 경기일 체크인 시 다시 표시됩니다.
- **의료진술서 무효화** — 재검진이 필요한 경우 Organizer 또는 Main Judge가 본인의 의료진술서를 무효화할 수 있습니다. 당사는 무효화 시각, 무효화한 사람, 입력된 사유를 이벤트 제출본과 본인 프로필에 저장된 사본 양쪽에 저장하고, 푸시 알림으로 본인에게 통지합니다. 사유 자체는 알림에 포함되지 않습니다. 무효화는 동일한 역할이 취소할 수 있습니다.

**보유 근거** — 이벤트를 안전하게 운영하고 AIDA 대회 규정을 준수하기 위함입니다. 이는 건강 정보이므로, 당사는 안전이 매우 중요한 스포츠에서 선수와 안전 요원의 생명에 관한 중대한 이익(vital interests)을 보호하기 위해 필요한 범위에서, 그리고 AIDA 대회 참가 시 동의하는 대회 규정이 요구하는 바에 따라 이를 처리합니다. 접근 권한은 해당 이벤트의 Organizer와 Main Judge로 제한되며, 위험 마킹만은 안전 관련 스태프도 볼 수 있습니다. 이 기록들은 이벤트 레코드의 일부로 보관되며 이벤트가 삭제될 때 함께 삭제됩니다.

### 2.12 공지 및 스태프 메시지

본 앱에는 이벤트 게시판(Board — Organizer 또는 Main Judge가 작성하고 해당 이벤트의 모든 참가자가 읽을 수 있는 공지)과 메시지(Dispatch — 이벤트 스태프가 선택한 스태프에게 보내는 메시지) 기능이 있습니다. 각 메시지에 대해 당사는 본문, 발신자의 이름과 이메일 주소, 시각을 저장하며, Dispatch의 경우 수신자 이메일 주소 목록도 저장합니다. 메시지가 푸시 알림으로 발송될 때 그 본문은 작성된 그대로 OneSignal에 전달되며 번역되지 않습니다. 메시지는 이벤트의 일부이며 이벤트가 삭제될 때 함께 삭제됩니다.

### 2.13 제외 기록

Organizer가 이벤트에서 사용자를 제외하면, 본 앱의 자동 선수 매칭이 해당 사용자를 다시 추가하여 Organizer의 결정을 조용히 되돌리는 일이 없도록 그 제외 사실을 기록으로 보관합니다. 이 기록에는 사용자의 이메일 주소, AIDA 선수 ID, 정규화된 이름 키, 제외한 사람, Organizer가 입력한 사유, 시각이 포함됩니다. 이 기록은 사용자가 더 이상 멤버가 아니게 된 후에도 해당 이벤트에 대해 보관되며, 일정에 따라 삭제되지 않습니다. Organizer는 새로운 개인 초대 코드를 발급하여 이를 해제할 수 있습니다. 5항을 참고하십시오.

### 2.14 Apple Watch 연동 앱

본 앱에는 Start List를 표시하고, Apple Watch Ultra에서는 잠수 중 수심, 다이브 시간, 수온을 보여주는 다이브 화면을 제공하는 Apple Watch 연동 앱이 포함되어 있습니다. 이를 위해 워치는 동작 및 피트니스(Motion & Fitness) 권한을 요청합니다. **수심, 수온, 다이브 시간은 워치에서만 표시됩니다** — 이 값들은 휴대폰, 당사 서버, AIDA, 그 밖의 누구에게도 전송되지 않으며 저장되지도 않습니다. 데이터는 한 방향으로만 흐릅니다. 휴대폰이 이벤트 이름, 사용자의 역할, 사용자의 이름, 그리고 안전 위험 마킹을 포함한 Start List를 워치로 보냅니다.

## 3. 정보 이용

수집된 정보는 다음 목적으로 이용됩니다.

- 사용자 인증 및 계정 관리
- 권한이 부여된 이벤트 스태프에게 대회 일정 및 선수 정보 제공
- 연동된 계정의 선수에게 Start List 및 본인 결과 제공
- 이벤트 운영자가 설정한 경우 AIDA International에 심판 결과 제출
- 이벤트 스태프의 여러 기기 간 실시간 데이터 동기화
- 이벤트 내 운영 투명성을 위한 활동 로그 유지
- AIDA 대회 규정에 따른 이의제기 관리 — 서명 캡처 및 jury 결정·수정 결과 기록 포함
- 업데이트 안내를 위해 서버측 최소 지원 앱 빌드(공개 설정값) 확인 — 이 확인은 어떠한 개인정보도 전송하지 않음
- OneSignal을 통한 푸시 알림 발송:
  * **수동 알림** — 이벤트 운영자가 발송하는 알림 (Start List 게시, 비공식 결과, 공식 결과)
  * **자동 알림** — 이벤트 상태에 따라 발송 (일정 변경/OT Delay 영향 선수 대상; 체크인 미완료 선수 대상 체크인 마감 알림; 이의제기 활동 — 제출, 선수 서명 대기, 결정); Organizer 또는 Main Judge가 등록한 게시판(Board) 공지; 이벤트 스태프가 본인에게 보낸 메시지(Dispatch); 서류 미제출 안내; 본인의 의료진술서가 무효화되었다는 통지. 게시판과 메시지의 본문은 작성된 그대로 발송되며 번역되지 않음
  * 알림 텍스트는 수신자의 앱 언어로 현지화됨 (게시판·메시지 본문은 예외)
- AIDA 규정에 따라 이벤트를 운영하는 데 필요한 안전·의료 정보 기록 (2.11항 참고)
- Organizer가 이벤트에서 제외한 참가자에 대한 기록 유지 — 자동 선수 매칭이 이들을 다시 추가하지 않도록 하기 위함 (2.13항 참고)
- 하나의 계정이 한 번에 하나의 기기에서만 로그인되도록 강제


당사는 사용자의 정보를 광고, 마케팅, 제3자 판매 목적으로 이용하지 **않습니다**.

## 4. 정보 공유

### 4.1 AIDA International과의 공유

이벤트 운영자가 AIDA API 토큰을 설정하여 AIDA 연동을 구성한 경우:

- AIDA International로부터 이벤트 일정, Start List, 선수 정보를 **읽어옴**
- AIDA International로 심판 결과(선수 기록, 카드, 페널티, REMARKS)를 **제출함**


이 공유는 본 앱의 핵심 기능에 필수적이며 이벤트 운영자에 의해 개시됩니다.

별도로, 선수가 **“AIDA에서 내 이름 찾기”(Find me on AIDA)** 기능을 사용하면 입력한 이름 텍스트가 AIDA International의 공개 선수 검색 서비스로 전송되어 일치하는 선수 프로필을 조회합니다. 검색어만 전송되며 계정 자격 정보나 기타 개인정보는 포함되지 않습니다.

또한 앱에서 선수 프로필을 열면 본 앱은 해당 선수의 AIDA 공개 프로필 페이지와 공개 결과 페이지를 요청합니다. 이때 전송되는 것은 해당 선수의 공개 AIDA UUID뿐입니다.

### 4.2 이벤트 내부

이벤트 참가자(organizer, main judge, judge, staff)는 다음을 볼 수 있습니다.

- 같은 이벤트의 다른 참가자의 이름, 프로필 사진, 역할
- 해당 이벤트의 선수 정보
- 심판 결과의 실시간 업데이트
- 활동 로그 (앱에서는 Organizer 및 Main Judge에게 표시됨; 2.6항 참고)


연동된 계정의 선수는 다음을 볼 수 있습니다.

- 본인이 등록된 이벤트의 Start List
- 본인의 경기 결과


정보는 이벤트 단위로 격리됩니다 — 한 이벤트의 사용자는 자신이 속하지 않은 다른 이벤트의 데이터를 볼 수 없습니다. 선수는 다른 선수의 개인 계정 정보를 볼 수 없습니다.

Sentry는 미국에서 해당 데이터를 처리합니다. Sentry 개인정보처리방침: [sentry.io/privacy](https://sentry.io/privacy/).


이들 제공자는 당사를 대신해 데이터를 처리하며 각자의 개인정보 처리방침을 따릅니다.

## 6. 데이터 보안

당사는 다음 다층 보안으로 정보를 보호합니다.

### 전송 및 저장

- 모든 데이터는 암호화된 HTTPS 연결로 전송됨
- 데이터는 인프라 제공자(Supabase)에 의해 저장 시 암호화됨
- 비밀번호는 업계 표준 알고리즘으로 해시되며, 평문 비밀번호는 절대 저장되지 않음


### 데이터베이스 수준 접근 통제

- 사용자 및 이벤트 데이터를 포함하는 모든 테이블에 **Row-Level Security(RLS)** 가 적용됨
- 사용자는 본인이 속한 이벤트의 데이터에만 접근 가능
- 승인 대기 또는 미승인 멤버는 이벤트 데이터에 접근 불가
- 로그인 시점이 아닌 모든 쿼리에서 권한이 검증됨


### 역할 기반 권한

- **Organizer / Main Judge** — 이벤트, 멤버, 대회 데이터 관리; 활동 로그 조회; 제출 서류 검토; 블랙아웃 후속 판단 기록; 수동 푸시 알림 발송 가능. Organizer는 **Observer**로 참가할 수 있으며, 이 경우 이벤트 멤버 목록에는 표시되지 않지만 동일한 권한을 가짐
- **Judge** — 대회 결과 조회 및 입력, 위험 마킹 설정, 이의제기 조회 가능
- **Safety** — 이벤트 데이터 조회 및 위험 마킹 설정 가능
- **Photo** — Start List 조회 및 본인이 촬영을 담당하는 선수 기록 가능
- **Staff** — 이벤트 데이터 조회 가능
- **Athlete** — Start List, 본인의 대회 결과, 본인이 제출한 서류, 본인과 관련된 이의제기에 대한 읽기 전용 접근
- 권한은 이벤트 단위로 격리되며, 한 이벤트의 심판은 다른 이벤트에 대한 접근 권한이 없음


### AIDA API 토큰 보호

- AIDA International 연동에 사용되는 AIDA API 토큰은 어떤 애플리케이션 역할도 직접 읽거나 쓸 수 없는 별도의 잠긴 데이터베이스 테이블에 보관됨. 모든 접근은 기본적으로 차단되며 제한된 서버측 함수를 통해서만 허용됨. 다른 모든 데이터와 마찬가지로 인프라 제공자에 의해 저장 시 암호화됨
- 제한된 데이터베이스 함수를 통해 main_judge 및 organizer 역할만 토큰을 가져올 수 있음
- 다른 역할(judge, staff, athlete)은 이벤트의 다른 데이터에 접근 가능하더라도 토큰에 접근할 수 없음
- 사용자 인터페이스에서 토큰은 마스킹되며, 사용자가 명시적으로 표시 옵션을 선택해야만 보임


### 세션 및 접근

- 인증 토큰은 단기 토큰이며 자동으로 갱신됨
- 이벤트에서 제거되면 접근 권한이 실시간으로 회수됨
- 계정 자격 정보는 사용자의 책임이며, 절대 공유하지 마십시오


당사는 합리적인 정보 보호 조치를 취하지만, 어떤 시스템도 완전히 안전할 수는 없습니다. 사용자는 본인의 계정 자격 정보를 비밀로 유지하고 의심스러운 활동을 신고할 책임이 있습니다.
