# 隐私政策

**Apnea Comp**

*最后更新: 2026年6月29日*

---


## 1. 简介

本隐私政策说明 **Apnea Comp** 移动应用程序（以下简称"我们"、"本应用"）在您使用我们的服务时如何收集、使用和保护信息。本应用是一款大会管理工具，专为参加 AIDA 认证大会的自由潜水赛事组织者、裁判、工作人员和运动员而设计。

使用本应用即表示您同意本政策中所述的处理方式。

---


## 2. 我们收集的信息

### 2.1 账户信息

当您创建账户时，我们会收集：

- **电子邮件地址** — 用于身份验证和账户恢复
- **显示名称（Display name）** — 向同一赛事的其他参与者显示
- **密码** — 通过我们的身份验证提供商（Supabase Auth）以安全哈希形式存储。我们绝不以明文存储密码。

### 2.2 个人资料信息（可选）

- **个人资料图片** — 如果您选择上传。该图片对您加入的任何赛事的其他成员可见，并在活动日志中被引用（见第 2.5 节）。

### 2.3 运动员账户关联（针对运动员）

如果您注册为运动员以查看出发名单和您本人的成绩，本应用将存储：

- **AIDA 运动员 UUID** — 来自 AIDA International 的永久标识符，用于将您的账户与您在赛事 Start List 中的出场记录进行匹配。仅在赛事组织者的邀请码经过验证，或您的姓名与赛事 Start List 匹配并获得批准之后，该 UUID 才会与您的账户关联。
- **同步的显示名称** — 您在 AIDA Start List 中公布的姓和名（First/Last name），在关联步骤中复制到您的个人资料
- **AIDA 搜索查询** — 当您使用"Find me on AIDA"功能查找您的运动员资料时，您输入的姓名会被发送到 AIDA International 的公开运动员搜索服务，以检索匹配的资料。仅传输您输入的文本；不包含任何账户凭据（见第 4.1 节）。

此数据仅保留在您本人的个人资料中，用于为您参加的赛事启用只读访问。

### 2.4 运动员比赛数据（从 AIDA 加载）

当赛事组织者从 AIDA International 加载赛事时，本应用将存储：

- **运动员姓名**（姓和名）
- **性别**
- **国籍**
- **项目**（STA、DYN、CWT 等）
- **公布成绩（Announced Performance, AP）**
- **个人最佳成绩（Personal Best, PB）**
- **比赛成绩**（RP、裁判卡片、判罚原因、REMARKS）
- **积分（Points）** — 根据成绩计算得出的大会积分
- **报名类型（Entry type）** — 区分某条报名是常规出发、*opener*（不计入排名且不发送至 AIDA 的热身报名），还是 *re-swim*（经申诉批准的重新表现）
- **有效性标志** — 当运动员进行 re-swim 时，原始报名会被标记为 *invalidated*，从而被排除在排名之外；但其仍会显示在 Results 中
- **签到状态** — 一个布尔标志，指示运动员是否在赛事现场签到。本应用在签到时会显示签名板，以便运动员确认出席，但**签名图像本身绝不会被存储** — 仅存储签名已发生这一事实。

除签到状态外，上述信息来源于 **AIDA International 的公开比赛记录**（通过其官方 API）。签到状态则直接在本应用内记录。

### 2.5 我们不收集的信息

我们明确**不**收集或存储：

- 运动员的电子邮件地址（运动员本人拥有账户时其本人的电子邮件除外）
- 运动员的电话号码
- 运动员的实际地址
- 运动员的照片或面部图像
- 签到签名图像（仅存储布尔标志）
- 用户的位置数据
- 用于追踪的设备标识符
- 浏览历史
- 您设备中的联系人

### 2.6 活动日志

为支持大会期间的运营透明度，本应用会记录在赛事内执行的重要操作：

- **我们记录的内容** — 裁判结果录入、日程调整（OT Delay）、签到操作以及成员角色变更
- **每条日志条目包含的内容** — 用户的显示名称、个人资料图片 URL（如已设置）、操作类型、受影响的运动员姓名（如适用）以及时间戳
- **可见范围** — 日志条目仅对同一赛事的 Organizer 和 Main Judge 可见
- **保留期限** — 日志条目与赛事绑定，并在赛事被删除时删除

活动日志不包含上述描述以外的任何数据。

### 2.7 推送通知数据

为向您的设备传递与赛事相关的通知，本应用将存储：

- **OneSignal Subscription ID** — 由我们的推送通知提供商（OneSignal）签发的设备专属标识符。仅用作通知的目标地址。
- **OneSignal external user ID** — 您的账户 ID，与 Subscription ID 关联，以便无论使用哪台设备，都能向您的账户发送通知。
- **Subscription 时间戳** — 最后更新时间，用于检测失效的订阅

这些值存储在您的账户个人资料中。当通知被禁用、本应用被卸载，或设备的通知权限被撤销时，Subscription ID 会被自动清除。

**注意：** Apnea Comp 此前使用 Firebase Cloud Messaging（FCM）进行推送传递。自 2026 年 5 月起，推送通知基础设施已迁移至 OneSignal。有关所涉第三方提供商的详细信息，请参见第 4.3 节。

### 2.8 设备本地存储

本应用出于两个目的在您的设备上本地存储有限的数据：

**离线缓冲（Judge 结果）**

为在网络连接间歇性中断时（在泳池和深度场地常见）仍能继续操作，本应用可能会在裁判结果到达我们的服务器之前，将其暂时保存在您设备的内存中：

- **位置** — 仅在本应用运行时的内存中。离线缓冲的裁判结果不会写入设备的持久存储。
- **时间** — 在设备离线时尝试保存裁判结果时自动进行。
- **时长** — 直到本应用将结果与我们的服务器同步为止，这会在网络恢复后数秒内自动完成。
- **可见范围** — 离线缓冲的结果仅在创建它们的设备上可见，直到同步成功。同一赛事中的其他设备看不到它们。
- **限制** — 如果在同步完成之前本应用被强制关闭或设备重启，离线缓冲的结果将丢失。本应用会在受影响的项目上显示"⛔ Offline"徽章，并警告用户在项目处于待处理状态时不要退出本应用。

**登录便利（Remember Email / Password）**

登录界面提供两个可选开关，可将凭据本地存储，以便在后续登录时预填：

- **Remember email** — 如启用，您的电子邮件地址将保存到设备的标准本地存储（Android 上为 SharedPreferences，iOS 上为 NSUserDefaults）。
- **Remember password** — 如启用，您的密码将保存到设备的**安全密钥库**（iOS Keychain / Android EncryptedSharedPreferences，AES-256，由操作系统加密）。它绝不会以明文存储，也绝不会传输到我们的服务器或任何第三方。它仅用于在同一设备上预填登录表单并恢复您的会话。
- **位置** — 仅在您的设备上。此信息不会传输到我们的服务器或任何第三方。
- **如何移除** — 在下次登录时取消勾选该选项、退出本应用（这会清除已存储的凭据），或卸载本应用。

**显示偏好（Display Preferences）**

您的主题选择（浅色 / 深色 / 系统）和应用语言会本地保存（SharedPreferences），以便本应用在每次启动之间记住它们。这些仅为偏好设置，不包含任何个人信息。

离线缓冲、登录便利和显示偏好存储均不会向任何第三方传输数据。

### 2.9 申诉（Protest）数据

当根据 AIDA 大会规则（规则手册 17.7）提交申诉时，本应用会存储一条 protest 记录，其中包含：

- **申诉理由** — 由提交申诉者输入的自由文本
- **运动员签名**以及（如适用）**Jury 签名** — 以手绘图像形式捕获并（以 base64 编码）存储在 protest 记录内。与签到签名板不同，由于已签署的申诉是官方比赛记录的一部分，因此**申诉签名会被保留**。
- **生成的申诉表单** — 一份嵌入了理由和签名的 PDF，存储在我们的后端文件存储（Supabase Storage）中
- **决定与修改** — jury 的决定（accepted / rejected / withdrawn），以及如被接受，修改后的成绩（card、RP、remarks）

**可见范围** — protest 记录对赛事的工作人员（Organizer、Main Judge、Judge）以及该申诉所涉及的运动员可见。申诉活动会触发推送通知（见第 3 节）。

### 2.10 提交文件（同意书及医疗证明）

当运动员加入赛事时，应用可能会收集并存储主办方所要求的同意及资格文件：

- **比赛报名表** — 性别、出生日期、出生国家、国籍、各项目个人最佳成绩，以及**您选择申报的健康相关病史**（最近一次压力性损伤／气压伤日期、最近一次黑视日期、最近一次体检日期）。
- **肖像权同意书**及**免责声明书** — 您的姓名、赛事名称及地点、签署日期，以及手绘签名。
- **医疗证明（可选）** — 包含检查／签发日期以及医师姓名、电话号码和手绘签名的医师健康适宜性证明。由于其证明您的健康状况，因此属于**敏感健康信息**。医疗证明有效期为一年，并可由您选择存储在您自己的个人资料中，以便在未来赛事中重复使用。
- **签名** — 运动员、见证人和医师的签名以手绘图像形式采集并嵌入所生成的文件中。与签到签名不同，这些签名将作为同意记录的一部分被**保留**。
- **上传的文件** — 如果您以照片或扫描件的形式提交文件，而非在应用中填写，则该图像文件将被存储。
- **生成的PDF** — 您在应用中填写完成的表单将渲染为PDF，并存储在我们的后端文件存储（Supabase Storage）中。

**可见范围** — 已提交的赛事文件可供该赛事的Organizer和Main Judge查看以进行核验，他们也可将其作为ZIP压缩包批量下载。如果您申报了受伤或黑视日期，工作人员将被提示手动核验您的医疗证明。

**提醒** — 如果在赛事前一天仍未提交必填文件，您可能会收到一条列出缺失文件的推送通知。

## 3. 我们如何使用信息

我们使用所收集的信息来：

- 验证用户身份并管理账户
- 向获授权的赛事工作人员显示比赛日程和运动员信息
- 向已关联账户的运动员显示 Start List 和个人成绩
- 将裁判结果提交回 AIDA International（在赛事组织者配置后）
- 在赛事工作人员使用的设备之间实时同步数据
- 维护活动日志，以实现赛事内的运营透明度
- 管理根据 AIDA 大会规则提交的申诉，包括捕获签名以及记录 jury 的决定和任何修改后的成绩
- 检查服务器端的最低支持应用版本（一个公开的配置值），以提示用户更新；此检查不传输任何个人数据
- 通过 OneSignal 发送推送通知，包括：
  * **手动通知** — 由赛事组织者触发（出发名单发布、非正式成绩、正式成绩）
  * **自动通知** — 由赛事状态触发（影响特定运动员的日程变更 / OT Delay；向尚未签到的运动员发送的签到截止提醒；申诉活动 — 已提交、等待运动员签名、已决定）
  * 通知文本会本地化为接收者的应用语言

我们**不会**将您的信息用于广告、营销或向第三方出售。

## 4. 数据共享

### 4.1 与 AIDA International 共享

当赛事组织者使用其 API 令牌配置 AIDA 集成时：

- 我们从 AIDA International **读取**赛事日期、出发名单和运动员信息
- 我们将裁判结果（运动员成绩、卡片、判罚、remarks）**提交**回 AIDA International

此共享对于本应用的核心功能至关重要，并由赛事组织者发起。

此外，当运动员使用 **"Find me on AIDA"** 功能时，本应用会将您输入的姓名文本发送到 AIDA International 的公开运动员搜索服务，以检索匹配的运动员资料。仅发送搜索文本；不包含任何账户凭据或其他个人数据。

### 4.2 赛事内部

赛事参与者（organizer、main judge、judge、staff）可以查看：

- 同一赛事中其他参与者的姓名、个人资料图片和角色
- 该赛事的运动员信息
- 裁判结果的实时更新
- 活动日志（仅限 Organizer 和 Main Judge）

已关联账户的运动员可以查看：

- 其出场赛事的 Start List
- 其本人的比赛成绩

信息按赛事范围隔离 — 某一赛事中的用户无法查看其不属于的另一赛事的数据。运动员无法查看其他运动员的个人账户信息。

### 4.3 第三方服务提供商

我们使用以下服务提供商来运营本应用：

- **Supabase** ([supabase.com](https://supabase.com)) — 后端身份验证、数据库、实时同步以及文件存储（个人资料图片和生成的申诉表单 PDF）
- **OneSignal** ([onesignal.com](https://onesignal.com)) — 向移动设备传递推送通知。当发送通知时，目标 Subscription ID、通知标题和通知正文会经过 OneSignal 的基础设施。OneSignal 还可能为优化传递而收集设备级元数据（设备型号、操作系统版本、语言、时区、国家/地区、IP 地址）。请参阅 OneSignal 的隐私政策：[onesignal.com/privacy](https://onesignal.com/privacy_policy)。OneSignal 随后会将通知有效负载转发至平台级推送服务 — 用于 iOS 的 Apple Push Notification service（APNs）和用于 Android 的 Firebase Cloud Messaging（FCM）— 以便最终传递到设备。
- **AIDA International** ([aidainternational.org](https://www.aidainternational.org)) — 比赛数据的官方来源
- **Apple App Store** 和 **Google Play Services** — 应用分发和崩溃报告

这些提供商代表我们处理数据，并受其各自隐私政策的约束。

### 4.4 法律要求

如果法律、法院命令要求，或为保护用户的权利、财产或安全，我们可能会披露信息。

## 5. 数据保留

- **账户数据** — 在您的账户存在期间保留。您可以随时请求删除（见第 8 节）。
- **赛事数据**（运动员、成绩、日志、签到状态、申诉） — 在赛事组织者删除赛事时自动删除。
- **申诉数据**（理由、签名、决定） — 作为赛事的一部分保留，并在组织者删除赛事时随赛事一同删除。存储在我们文件存储中的生成的申诉 PDF 会在单条申诉被删除时移除，并且在任何情况下都会**在生成 30 天后自动删除**。
- **提交文件**（比赛报名、肖像权、免责声明，以及赛事提交的医疗证明） — 作为赛事的一部分保留，并在**赛事结束 15 天后自动删除**。您保存到自己个人资料中的医疗证明会在其一年有效期内保留，并可随时撤回。
- **OneSignal Subscription ID** — 当您禁用通知、卸载本应用或撤销设备上的通知权限时自动清除。反复发送失败的订阅（例如设备不再可达）也会被 OneSignal 自动清除。
- **本地存储的凭据**（Remember email / Remember password） — 保留在您的设备上，直到您禁用该选项、退出登录或卸载本应用。
- **离线缓冲的结果** — 仅保留在设备内存中；在网络恢复后数秒内同步到我们的服务器，或在同步前本应用被关闭时丢失。
- **身份验证令牌** — 短期有效；自动刷新或过期。

## 6. 数据安全

我们通过多层安全措施保护您的信息：

### 传输与存储

- 所有数据均通过加密的 HTTPS 连接传输
- 数据由我们的基础设施提供商（Supabase）静态加密
- 密码使用行业标准算法进行哈希处理；我们绝不存储明文密码

### 数据库级访问控制

- 在包含用户或赛事数据的所有表上，于数据库级别强制执行 **Row-Level Security（RLS）**
- 用户只能访问其所属赛事的数据
- 待批准或未批准的成员无法访问赛事数据
- 权限在每次查询时都会检查，而不仅是在登录时

### 基于角色的权限

- **Main Judge / Organizer** — 可管理赛事、成员和比赛数据；查看活动日志；发送手动推送通知
- **Judge** — 可查看和提交比赛成绩
- **Staff** — 可查看赛事数据
- **Athlete** — 对 Start List 和个人比赛成绩的只读访问
- 权限按赛事范围隔离；某一赛事中的裁判无权访问另一赛事

### AIDA API 令牌保护

- 用于与 AIDA International 同步的 AIDA API 令牌以加密形式存储在数据库中
- 只有 main_judge 和 organizer 角色才能检索令牌，并通过受限的数据库函数强制执行
- 其他角色（judge、staff、athlete）即使有权访问其他赛事数据，也无法访问令牌
- 令牌在用户界面中被遮蔽；用户必须明确选择才能显示它们

### 会话与访问

- 身份验证令牌为短期有效，并自动刷新
- 当用户从赛事中被移除时，访问权限会被实时撤销
- 账户凭据由您负责；切勿共享它们

虽然我们采取合理措施来保护您的信息，但没有任何系统是完全安全的。您有责任对您的账户凭据保密，并报告任何可疑活动。

## 7. 儿童隐私

本应用旨在供成年的赛事组织者、裁判、工作人员和运动员（通常为 18 岁及以上）使用。我们不会在知情的情况下收集 13 岁以下儿童的个人信息。AIDA International 的比赛记录可能包含各种年龄的运动员，但本应用不会收集任何个人（包括未成年人）的联系信息。

如果您认为我们在未经父母同意的情况下收集了儿童的信息，请联系我们，以便我们将其删除。

## 8. 您的权利

您有权：

- **访问**我们持有的关于您的个人信息
- 通过本应用的个人资料设置**更正**不准确的信息
- **删除**您的账户和相关数据
- 通过卸载本应用并请求删除账户来**撤回同意**
- 通过您设备的系统设置或本应用的通知偏好**禁用通知**。禁用通知会立即停止使用您的推送订阅，并将其从我们的服务器和 OneSignal 中清除。
- **导出**您的数据（如需协助请联系我们）

要行使这些权利，请使用第 11 节中的信息联系我们。
