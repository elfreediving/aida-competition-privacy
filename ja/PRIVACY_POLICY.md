# プライバシーポリシー

**Apnea Comp**

*最終更新日: 2026年8月22日*

---


## 1. はじめに

本プライバシーポリシーは、**Apnea Comp** モバイルアプリケーション（以下「当社」、「本アプリ」）が、お客様による本サービスのご利用に際して情報をどのように収集、利用、保護するかについて説明するものです。本アプリは、AIDA 公認大会に参加するフリーダイビングのイベント運営者、審判、スタッフ、および選手のために設計された大会管理ツールです。

本アプリをご利用いただくことにより、お客様は本ポリシーに記載された取扱いに同意したものとみなされます。

---


## 2. 当社が収集する情報

### 2.1 アカウント情報

アカウントを作成する際、当社は以下を収集します。

- **メールアドレス** — 認証およびアカウント復旧のために使用します
- **表示名（Display name）** — 同じイベントの他の参加者に表示されます
- **パスワード** — 当社の認証プロバイダ（Supabase Auth）を通じて安全なハッシュ形式で保存されます。当社がパスワードを平文で保存することは決してありません


**Apple または Google でのサインイン。** メールアドレスとパスワードによるログインの代わりに、Apple または Google アカウントを使用してサインインすることができます。その際、当社はアカウントを作成または識別するために、Apple または Google から**氏名**と**メールアドレス**を受け取ります。**Sign in with Apple** を使用し、メールアドレスを非公開にすることを選択された場合、Apple は実際のアドレスの代わりに非公開のリレーメールアドレスを当社に提供し、当社はこれを他のメールアドレスと同じように使用します。当社が Apple または Google のパスワードを受け取ることは決してありません — サインインは、各プロバイダと当社の認証プロバイダ（Supabase Auth）が共同で処理します。


### 2.2 プロフィール情報（任意）

- **プロフィール画像** — アップロードを選択した場合に保存されます。この画像は、お客様が参加するイベントの他のメンバーに表示され、アクティビティログ（2.6項参照）でも参照されます

### 2.3 選手アカウントの連携（選手の方向け）

Start List およびご自身の結果を閲覧するために選手として登録される場合、本アプリは以下を保存します。

- **AIDA 選手 UUID** — AIDA International が付与する永続的な識別子で、お客様のアカウントをイベントの Start List 上のお客様の出場記録と照合するために使用されます。この UUID は、イベント運営者の招待コードが確認されるか、お客様の氏名がイベントの Start List と照合され承認された後にのみ、お客様のアカウントに関連付けられます。
- **同期された表示名** — AIDA の Start List に公開されているお客様の氏名（First/Last name）で、連携の段階でお客様のプロフィールにコピーされます
- **AIDA 検索クエリ** — 「Find me on AIDA」機能を使用してご自身の選手プロフィールを検索する際、入力された氏名が AIDA International の公開選手検索サービスに送信され、一致するプロフィールを取得します。送信されるのは入力されたテキストのみであり、アカウントの認証情報は含まれません（4.1項参照）

このデータは、お客様が参加するイベントへの読み取り専用アクセスを可能にするため、お客様ご自身のプロフィールにのみ保持されます。

### 2.4 選手の競技データ（AIDA から読み込み）

イベント運営者が AIDA International からイベントを読み込む際、本アプリは以下を保存します。

- **選手名**（First/Last name）
- **性別**
- **国籍**
- **種目**（STA、DYN、CWT など）
- **公式申告記録（Announced Performance, AP）**
- **自己ベスト（Personal Best, PB）**
- **競技結果**（RP、審判カード、ペナルティ理由、REMARKS）
- **ポイント（Points）** — 結果から算出された大会ポイント
- **エントリー種別（Entry type）** — 通常のスタートか、*opener*（ランキングから除外され AIDA にも送信されないウォームアップエントリー）か、*re-swim*（プロテストを通じて承認された再演技）かの区別
- **有効性フラグ** — 選手が re-swim を行うと、元のエントリーは *invalidated* としてマークされ、ランキングから除外されます。ただし Results には引き続き表示されます
- **チェックイン状況** — 選手がイベント会場で受付を行ったかどうかを示すブール値フラグ。本アプリはチェックイン時に署名パッドを表示し、選手が出席を確認できるようにしますが、**署名画像そのものは一切保存されません** — 署名が行われたという事実のみが保存されます

これらの情報は、チェックイン状況を除き、**AIDA International の公開競技記録**から公式 API を経由して取得されます。チェックイン状況は本アプリ内で直接記録されます。

### 2.5 当社が収集しない情報

当社は、以下を明確に収集または保存**しません**。

- 選手のメールアドレス（選手本人がアカウントを持っている場合の本人のメールアドレスを除く）
- 選手の電話番号
- 選手の住所
- 選手の写真または顔画像
- チェックインの署名画像（ブール値フラグのみ保存）
- ユーザーの位置情報
- 追跡用のデバイス識別子
- 閲覧履歴
- お客様のデバイスの連絡先

### 2.6 アクティビティログ

大会中の運用上の透明性を確保するため、本アプリはイベント内で行われた重要な操作を記録します。

- **記録対象** — 審判による結果入力、スケジュール調整（OT Delay）、チェックイン操作、メンバーの役割変更
- **各ログ項目に含まれる内容** — ユーザーの表示名、プロフィール画像 URL（設定されている場合）、操作の種類、影響を受けた選手名（該当する場合）、およびタイムスタンプ
- **公開範囲** — 同じイベントの Organizer および Main Judge にのみ表示されます
- **保持期間** — ログ項目はイベントに紐づき、イベントが削除されると削除されます

アクティビティログには、上記に記載された以外のいかなるデータも含まれません。

### 2.7 プッシュ通知データ

イベント関連の通知をお客様のデバイスに配信するため、本アプリは以下を保存します。

- **OneSignal Subscription ID** — 当社のプッシュ通知プロバイダ（OneSignal）が発行するデバイス固有の識別子。通知の送信先アドレスとしてのみ使用されます。
- **OneSignal external user ID** — お客様のアカウント ID で、Subscription ID と紐づけられ、デバイスを問わずお客様のアカウント宛てに通知を送信できるようにします。
- **Subscription のタイムスタンプ** — 最終更新時刻で、無効になった購読を検出するために使用されます

これらの値はお客様のアカウントプロフィールに保存されます。Subscription ID は、通知が無効化されたとき、本アプリがアンインストールされたとき、またはデバイスの通知許可が取り消されたときに自動的にクリアされます。

**注:** Apnea Comp は以前、プッシュ配信に Firebase Cloud Messaging（FCM）を使用していました。2026年5月をもって、プッシュ通知インフラは OneSignal へ移行されました。関連する第三者プロバイダの詳細については 4.3項をご参照ください。

### 2.8 デバイスのローカルストレージ

本アプリは、2 つの目的のために、お客様のデバイス上に限られたデータをローカルに保存します。

**オフラインバッファリング（Judge 結果）**

インターネット接続が断続的になる状況（プールおよびデプスの会場で一般的です）でも操作を継続できるようにするため、本アプリは審判結果が当社サーバーに到達する前に、一時的にお客様のデバイスのメモリに保持する場合があります。

- **場所** — 本アプリの実行中のメモリ内のみ。オフラインバッファリングされた審判結果は、デバイスの永続ストレージには書き込まれません。
- **タイミング** — オフライン状態で審判が結果の保存を試みた際に自動的に行われます。
- **保持期間** — 本アプリが結果を当社サーバーと同期するまで。同期はインターネットが復旧してから数秒以内に自動的に行われます。
- **公開範囲** — オフラインバッファリングされた結果は、同期が成功するまで、それを作成したデバイス上でのみ表示されます。同じイベントの他のデバイスには表示されません。
- **制約** — 同期が完了する前に本アプリが強制終了されたり、デバイスが再起動されたりすると、オフラインバッファリングされた結果は失われます。本アプリは該当する項目に「⛔ Offline」バッジを表示し、項目が保留中の間は本アプリを終了しないようユーザーに警告します。

**ログイン時の利便性（Remember Email / Password）**

ログイン画面には、次回以降のログイン時に事前入力されるよう、認証情報をローカルに保存する 2 つの任意トグルがあります。

- **Remember email** — 有効にすると、お客様のメールアドレスがデバイスの標準ローカルストレージ（Android では SharedPreferences、iOS では NSUserDefaults）に保存されます。
- **Remember password** — 有効にすると、お客様のパスワードがデバイスの**セキュアキーストア**（iOS Keychain / Android EncryptedSharedPreferences、AES-256、オペレーティングシステムによって暗号化）に保存されます。平文で保存されることは決してなく、当社サーバーや第三者に送信されることもありません。同じデバイス上でログインフォームを事前入力し、セッションを復元する目的にのみ使用されます。
- **場所** — お客様のデバイス上のみ。この情報は当社サーバーや第三者に送信されません。
- **削除方法** — 次回のログイン時にオプションのチェックを外す、本アプリからサインアウトする（保存された認証情報がクリアされます）、または本アプリをアンインストールします。

**表示設定（Display Preferences）**

お客様のテーマ選択（ライト / ダーク / システム）とアプリの言語は、本アプリが起動間で記憶できるよう、ローカル（SharedPreferences）に保存されます。これらは設定項目のみであり、個人情報を含みません。

オフラインバッファリング、ログイン時の利便性、表示設定の保存のいずれも、第三者にデータを送信することはありません。

### 2.9 プロテストデータ

AIDA 大会規則（ルールブック 17.7）に基づきプロテストが提出されると、本アプリは以下を含む protest レコードを保存します。

- **プロテスト理由** — プロテストを提出する者が入力する自由記述テキスト
- **選手の署名** および、該当する場合は **Jury の署名** — 手書きの画像としてキャプチャされ、protest レコード内に（base64 でエンコードして）保存されます。チェックインの署名パッドとは異なり、署名されたプロテストは公式の競技記録の一部であるため、**プロテストの署名は保持されます**。
- **生成されたプロテスト用紙** — 理由と署名を埋め込んだ PDF で、当社のバックエンドのファイルストレージ（Supabase Storage）に保存されます
- **決定および修正内容** — jury の決定（accepted / rejected / withdrawn）、および承認された場合は修正後の結果（card、RP、remarks）

**公開範囲** — protest レコードは、イベントのスタッフ（Organizer、Main Judge、Judge）およびそのプロテストが関係する選手に表示されます。プロテストの活動はプッシュ通知をトリガーします（3項参照）。

### 2.10 提出書類（同意書および医療診断書）

選手がイベントに参加する際、本アプリは、主催者が要求する同意および資格に関する書類を収集し保存する場合があります。

- **大会参加申込書** — 性別、生年月日、出生国、国籍、種目別の自己ベスト記録、および**ご自身が選択して申告する健康関連の履歴**（最近の圧力損傷 / 気圧外傷の日付、最近のブラックアウトの日付、最近の健康診断の日付）。
- **肖像権同意書** および **責任免除同意書** — 本人の氏名、イベント名および場所、署名日、ならびに手書きの署名。
- **医療診断書（任意）** — 検診 / 発行日、ならびに医師の氏名、電話番号、手書きの署名を含む、医師による適性診断書。ご自身の健康を証明する書類であるため、これは**センシティブな健康情報**です。医療診断書は 1 年間有効であり、ご自身の選択により、今後のイベントで再利用できるようご自身のプロフィールに保存されます。
- **署名** — 選手、証人、および医師の署名は手書きの画像としてキャプチャされ、生成される書類に埋め込まれます。チェックインの署名とは異なり、これらの署名は同意記録の一部として**保持されます**。
- **アップロードされたファイル** — 本アプリ内で直接記入する代わりに、書類を写真またはスキャンとして提出する場合、その画像ファイルが保存されます。
- **生成された PDF** — 本アプリ内で記入した書類は PDF としてレンダリングされ、当社のバックエンドのファイルストレージ（Supabase Storage）に保存されます。

**公開範囲** — 提出されたイベント書類は、検証のためにイベントの Organizer および Main Judge が閲覧でき、これらの担当者は書類を ZIP アーカイブとして一括ダウンロードすることもできます。負傷またはブラックアウトの日付を申告した場合、スタッフに対して医療診断書を手動で検証するよう案内が表示されます。

**リマインダー** — 必須書類をイベントの前日までに提出しなかった場合、不足している書類を案内するプッシュ通知を受け取ることがあります。

## 3. 情報の利用方法

当社は、収集した情報を以下の目的で利用します。

- ユーザーの認証およびアカウントの管理
- 権限を有するイベントスタッフへの大会スケジュールおよび選手情報の表示
- アカウントを連携した選手への Start List および個人結果の表示
- AIDA International への審判結果の提出（イベント運営者が設定した場合）
- イベントスタッフが使用する複数のデバイス間でのリアルタイムなデータ同期
- イベント内の運用上の透明性のためのアクティビティログの維持
- AIDA 大会規則に基づき提出されたプロテストの管理（署名のキャプチャ、ならびに jury の決定および修正後の結果の記録を含む）
- ユーザーに更新を促すための、サーバー側の最小サポートアプリバージョン（公開された設定値）の確認。この確認では個人データは一切送信されません
- OneSignal を通じたプッシュ通知の送信。以下を含みます。
  * **手動通知** — イベント運営者によってトリガーされるもの（Start List の公開、非公式結果、公式結果）
  * **自動通知** — イベントの状態によってトリガーされるもの（特定の選手に影響するスケジュール変更 / OT Delay、まだチェックインしていない選手へのチェックイン締切リマインダー、プロテストの活動 — 提出、選手の署名待ち、決定）
  * 通知のテキストは受信者のアプリ言語にローカライズされます

当社は、お客様の情報を広告、マーケティング、または第三者への販売のために利用することは**ありません**。

## 4. データの共有

### 4.1 AIDA International との共有

イベント運営者が API トークンを用いて AIDA 連携を設定した場合：

- 当社は AIDA International からイベントの日程、Start List、および選手情報を**読み取ります**
- 当社は審判結果（選手の記録、カード、ペナルティ、remarks）を AIDA International に**提出します**

この共有は本アプリの中核機能に不可欠であり、イベント運営者によって開始されます。

これとは別に、選手が **「Find me on AIDA」** 機能を使用すると、本アプリは入力された氏名のテキストを AIDA International の公開選手検索サービスに送信し、一致する選手プロフィールを取得します。送信されるのは検索テキストのみであり、アカウントの認証情報やその他の個人データは含まれません。

### 4.2 イベント内

イベント参加者（organizer、main judge、judge、staff）は、以下を閲覧できます。

- 同じイベントの他の参加者の氏名、プロフィール画像、役割
- そのイベントの選手情報
- 審判結果のリアルタイム更新
- アクティビティログ（Organizer および Main Judge のみ）

アカウントを連携した選手は、以下を閲覧できます。

- 本人が出場するイベントの Start List
- 本人の競技結果

情報はイベント単位に限定されます — あるイベントのユーザーは、自分が属していない別のイベントのデータを閲覧できません。選手は、他の選手の個人アカウント情報を閲覧できません。

### 4.3 第三者サービスプロバイダ

当社は、本アプリを運営するために以下のサービスプロバイダを利用しています。

- **Supabase** ([supabase.com](https://supabase.com)) — バックエンドの認証、データベース、リアルタイム同期、およびファイルストレージ（プロフィール画像および生成されたプロテスト用紙の PDF）
- **Apple — Sign in with Apple** — Apple でのサインインを選択された場合、Apple がお客様を認証し、お客様の氏名とメールアドレス（または非公開のリレーメールアドレス）を当社に共有します。Apple のプライバシーポリシーは [apple.com/legal/privacy](https://www.apple.com/legal/privacy/) をご参照ください。
- **Google — Google Sign-In** — Google でのサインインを選択された場合、Google がお客様を認証し、お客様の氏名とメールアドレスを当社に共有します。Google のプライバシーポリシーは [policies.google.com/privacy](https://policies.google.com/privacy) をご参照ください。
- **OneSignal** ([onesignal.com](https://onesignal.com)) — モバイルデバイスへのプッシュ通知の配信。通知が送信される際、送信先の Subscription ID、通知のタイトル、および通知の本文が OneSignal のインフラを経由します。OneSignal は、配信の最適化のために、デバイスレベルのメタデータ（デバイスのモデル、OS のバージョン、言語、タイムゾーン、国、IP アドレス）を収集する場合があります。OneSignal のプライバシーポリシーは [onesignal.com/privacy](https://onesignal.com/privacy_policy) をご参照ください。OneSignal はさらに、通知のペイロードをプラットフォームレベルのプッシュサービス — iOS 向けの Apple Push Notification service（APNs）および Android 向けの Firebase Cloud Messaging（FCM）— に転送し、デバイスへの最終的な配信を行います。
- **AIDA International** ([aidainternational.org](https://www.aidainternational.org)) — 競技データの公式な提供元
- **Apple App Store** および **Google Play Services** — アプリの配布およびクラッシュレポート
- **Sentry** ([sentry.io](https://sentry.io)) — エラー・クラッシュの自動診断。アプリでクラッシュや予期しないエラーが発生した場合、エラーの種類、発生したコードの位置、アプリのバージョンとビルド番号、端末モデル、OS バージョンを含む診断レポートが送信されます。このレポートは**データ最小化**の方針で設定されています。IP アドレスや端末識別子を送信**せず**、スクリーンショットや画面の内容を取得**せず**、リクエスト本文・認証トークン・アカウント情報を含**まず**、利用状況や行動を追跡**しません**。エラーメッセージに含まれるテキストは送信前に除去処理され、メールアドレスはマスクされ、署名画像などの長いエンコード値は削除されます。除去処理が完了できない場合、レポートは送信されずに破棄されます。レポートは不具合の発見と修正のみに使用され、特にアプリの安全関連機能において重要です。Sentry は当該データを米国で処理します。Sentry のプライバシーポリシー：[sentry.io/privacy](https://sentry.io/privacy/)。

これらのプロバイダは当社に代わってデータを処理し、各自のプライバシーポリシーに拘束されます。

### 4.4 法的要件

当社は、法律、裁判所の命令により要求される場合、またはユーザーの権利、財産、もしくは安全を保護するために、情報を開示することがあります。

## 5. データの保持

- **アカウントデータ** — お客様のアカウントが存在する間、保持されます。お客様はいつでも削除を要求できます（8項参照）。
- **イベントデータ**（選手、結果、ログ、チェックイン状況、プロテスト） — イベント運営者がイベントを削除すると自動的に削除されます。
- **プロテストデータ**（理由、署名、決定） — イベントの一部として保持され、運営者がイベントを削除する際にイベントとともに削除されます。当社のファイルストレージに保存された生成済みのプロテスト PDF は、個々のプロテストが削除されると除去され、いかなる場合でも **生成から30日後に自動的に削除されます**。
- **提出書類**（大会参加申込書、肖像権同意書、責任免除同意書、およびイベントに提出された医療診断書） — イベントの一部として保持され、**イベント終了の15日後に自動的に削除されます**。ご自身のプロフィールに保存した医療診断書は、その 1 年間の有効期間中は保持され、いつでも撤回することができます。
- **OneSignal Subscription ID** — お客様が通知を無効化したとき、本アプリをアンインストールしたとき、またはデバイスの通知許可を取り消したときに自動的にクリアされます。繰り返し送信に失敗する購読（例：デバイスにもはや到達できない場合）も、OneSignal によって自動的にクリアされます。
- **ローカルに保存された認証情報**（Remember email / Remember password） — お客様がオプションを無効にするか、サインアウトするか、本アプリをアンインストールするまで、お客様のデバイスに保持されます。
- **オフラインバッファリングされた結果** — デバイスのメモリ内にのみ保持されます。インターネットが復旧してから数秒以内に当社サーバーに同期されるか、同期前に本アプリが終了されると失われます。
- **認証トークン** — 短命であり、自動的に更新または期限切れになります。

## 6. データセキュリティ

当社は、複数の層のセキュリティによってお客様の情報を保護します。

### 転送と保存

- すべてのデータは暗号化された HTTPS 接続で転送されます
- データは当社のインフラプロバイダ（Supabase）によって保存時に暗号化されます
- パスワードは業界標準のアルゴリズムでハッシュ化され、平文のパスワードを保存することは決してありません

### データベースレベルのアクセス制御

- ユーザーまたはイベントのデータを含むすべてのテーブルに、データベースレベルで **Row-Level Security（RLS）** が適用されます
- ユーザーは、自分が属するイベントのデータにのみアクセスできます
- 承認待ちまたは未承認のメンバーは、イベントデータにアクセスできません
- 権限はログイン時だけでなく、すべてのクエリで検証されます

### 役割ベースの権限

- **Main Judge / Organizer** — イベント、メンバー、競技データの管理、アクティビティログの閲覧、手動プッシュ通知の送信が可能
- **Judge** — 競技結果の閲覧および入力が可能
- **Staff** — イベントデータの閲覧が可能
- **Athlete** — Start List および個人の競技結果への読み取り専用アクセス
- 権限はイベントごとに限定され、あるイベントの審判は別のイベントへのアクセス権を持ちません

### AIDA API トークンの保護

- AIDA International との同期に使用される AIDA API トークンは、データベースに暗号化して保存されます
- トークンを取得できるのは main_judge および organizer の役割のみであり、制限されたデータベース関数を通じて強制されます
- その他の役割（judge、staff、athlete）は、イベントの他のデータにアクセスできる場合でも、トークンにアクセスできません
- トークンはユーザーインターフェース上でマスクされ、ユーザーが明示的に表示を選択した場合にのみ表示されます

### セッションとアクセス

- 認証トークンは短命であり、自動的に更新されます
- ユーザーがイベントから削除されると、アクセス権はリアルタイムで取り消されます
- アカウントの認証情報はお客様の責任であり、決して共有しないでください

当社はお客様の情報を保護するために合理的な対策を講じていますが、完全に安全なシステムは存在しません。お客様は、ご自身のアカウントの認証情報を秘密に保ち、不審な活動を報告する責任を負います。

## 9. 国際的なデータ移転

本アプリは、当社のサービスプロバイダが運営する地域でデータを処理および保存する場合があります。Supabase のデータは、韓国（ソウルリージョン）および日本（東京リージョン）に保存されています。プッシュ通知は OneSignal を通じて配信され、OneSignal はグローバルに運営されており、米国およびそのインフラが所在するその他の地域で通知のメタデータを処理する場合があります。OneSignal はさらに、通知を Apple Push Notification service（APNs）および Firebase Cloud Messaging（FCM）を通じて転送し、これらもグローバルに運営されています。エラー・クラッシュ診断は Sentry により米国で処理され、当該レポートに個人情報は含まれません（4.3 項参照）。本アプリをご利用いただくことにより、お客様は、お客様のデータがこれらの地域に移転され処理されることに同意したものとみなされます。
