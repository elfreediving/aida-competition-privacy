# プライバシーポリシー

**Apnea Comp**

*最終更新日: 2026年9月18日*

---


## 1. はじめに

本プライバシーポリシーは、**Apnea Comp** モバイルアプリケーション（以下「当社」、「本アプリ」）が、お客様による本サービスのご利用に際して情報をどのように収集、利用、保護するかについて説明するものです。本アプリは、AIDA 公認大会に参加するフリーダイビングのイベント運営者、審判、スタッフ、および選手のために設計された大会管理ツールです。

本アプリをご利用いただくことにより、お客様は本ポリシーに記載された取扱いに同意したものとみなされます。

---


## 2. 当社が収集する情報

### 2.1 アカウント情報

アカウントを作成する際、当社は以下を収集します。

- **メールアドレス** — 認証およびアカウント復旧のために使用します
- **表示名（Display name）** — 同じイベントの他の参加者に表示されます
- **パスワード** — 当社の認証プロバイダ（Supabase Auth）を通じて安全なハッシュ形式で保存されます。当社がパスワードを平文で保存することは決してありません


**Apple または Google でのサインイン。** メールアドレスとパスワードによるログインの代わりに、Apple または Google アカウントを使用してサインインすることができます。その際、当社はアカウントを作成または識別するために、Apple または Google から**氏名**と**メールアドレス**を受け取ります。**Sign in with Apple** を使用し、メールアドレスを非公開にすることを選択された場合、Apple は実際のアドレスの代わりに非公開のリレーメールアドレスを当社に提供し、当社はこれを他のメールアドレスと同じように使用します。当社が Apple または Google のパスワードを受け取ることは決してありません — サインインは、各プロバイダと当社の認証プロバイダ（Supabase Auth）が共同で処理します。


### 2.2 プロフィール情報（任意）

- **プロフィール画像** — アップロードを選択した場合に保存されます。この画像は、お客様が参加するイベントの他のメンバーに表示され、アクティビティログ（2.6項参照）でも参照されます

### 2.3 選手アカウントの連携（選手の方向け）

Start List およびご自身の結果を閲覧するために選手として登録される場合、本アプリは以下を保存します。

- **AIDA 選手 UUID** — AIDA International が付与する永続的な識別子で、お客様のアカウントをイベントの Start List 上のお客様の出場記録と照合するために使用されます。この UUID は、イベント運営者の招待コードが確認されるか、お客様の氏名がイベントの Start List と照合され承認された後にのみ、お客様のアカウントに関連付けられます。
- **同期された表示名** — AIDA の Start List に公開されているお客様の氏名（First/Last name）で、連携の段階でお客様のプロフィールにコピーされます
- **AIDA 検索クエリ** — 「AIDAで自分を検索」（Find me on AIDA）機能を使用してご自身の選手プロフィールを検索する際、入力された氏名が AIDA International の公開選手検索サービスに送信され、一致するプロフィールを取得します。送信されるのは入力されたテキストのみであり、アカウントの認証情報は含まれません（4.1項参照）
- **AIDA 公開プロフィールの参照** — 本アプリ内で選手プロフィールが開かれると、本アプリはその選手の AIDA UUID を用いて AIDA International のウェブサイトから当該選手の公開プロフィールページおよび公開結果ページを取得し、AIDA が公開している種目別の競技記録、国内 / 大陸 / 世界ランキング、大会出場履歴、およびプロフィール写真を表示します。アカウントの認証情報は送信されず、当社がその複製を保存することもありません。取得した内容はその時点のセッション中に限り本アプリのメモリ上に保持され、本アプリを再起動すると破棄されます。

このデータは、お客様が参加するイベントへの読み取り専用アクセスを可能にするため、お客様ご自身のプロフィールにのみ保持されます。

### 2.4 選手の競技データ（AIDA から読み込み）

イベント運営者が AIDA International からイベントを読み込む際、本アプリは以下を保存します。

- **選手名**（First/Last name）
- **性別**
- **国籍**
- **種目**（STA、DYN、CWT など）
- **公式申告記録（Announced Performance, AP）**
- **自己ベスト（Personal Best, PB）**
- **競技結果**（RP、審判カード、ペナルティ理由、REMARKS）
- **ポイント（Points）** — 結果から算出された大会ポイント
- **エントリー種別（Entry type）** — 通常のスタートか、*opener*（ランキングから除外され AIDA にも送信されないウォームアップエントリー）か、*re-swim*（プロテストを通じて承認された再演技）かの区別
- **有効性フラグ** — 選手が re-swim を行うと、元のエントリーは *invalidated* としてマークされ、ランキングから除外されます。ただし Results には引き続き表示されます
- **チェックイン状況** — 選手が受付前（pending）、受付済み（checked in）、遅刻受付（checked in late）、不参加（DNS）のいずれであるか、およびチェックインの時刻。遅刻受付および DNS は AIDA 規則に基づく競技上のペナルティを伴い、本アプリは、チェックイン締切を過ぎた選手を自動的に遅刻として記録する場合があります。本アプリはチェックイン時に署名パッドを表示し、選手が出席を確認できるようにしますが、**署名画像そのものは一切保存されません** — 署名が行われたという事実のみが保存されます
- **リスクマーキング** — イベントスタッフが選手に設定できる安全上のフラグ（2.11項参照）

これらの情報は、チェックイン状況およびリスクマーキングを除き、**AIDA International の公開競技記録**から公式 API を経由して取得されます。チェックイン状況およびリスクマーキングは、本アプリ内で直接記録されます。

### 2.5 当社が収集しない情報

当社は、以下を明確に収集または保存**しません**。

- 選手のメールアドレス（選手ご本人がアカウントをお持ちの場合のご本人のアドレス、および運営者に表示されるイベントメンバーのアドレスを除く）
- 選手の電話番号（お客様が任意で提出する医療診断書に記載される医師の連絡先番号を除く）
- 選手の住所
- チェックインの署名画像（ブール値フラグのみ保存）
- ユーザーの位置情報
- 広告またはアプリ間トラッキングのための識別子、およびお客様のデータの広告目的での利用
- 閲覧履歴
- お客様のデバイスの連絡先

当社は、お客様がサインインしたデバイスについて、ランダムに生成された識別子を保存します。これは本アプリが生成するもので、いかなるハードウェア識別子からも導出されません。この識別子は、1 つのアカウントが同時に 1 台のデバイスでのみサインインしている状態を保つこと、およびイベント中に Speaker Mode のデバイスのサインイン状態を維持することのみに使用されます。

当社は選手の顔写真を保存しません。お客様ご自身がアップロードしたプロフィール画像は保存されます（2.2項）。また、AIDA International が公開している選手のプロフィール写真は、プロフィールが開かれた際に AIDA の公開ウェブサイトから読み込まれて本アプリ上に表示されます（2.3項）。

### 2.6 アクティビティログ

大会中の運用上の透明性を確保するため、本アプリはイベント内で行われた重要な操作を記録します。

- **記録対象** — 審判による結果の入力および訂正、スケジュール調整（OT Delay）、チェックイン操作（システムによる自動の遅刻マーキングを含む）、Setup および Start List の変更、通知の送信および取消、メンバーの役割変更、ならびに選手の医療診断書に対する操作（無効化、復元、およびチェックイン時における過去のブラックアウトの確認）
- **各ログ項目に含まれる内容** — ユーザーの表示名、プロフィール画像 URL（設定されている場合）、操作の種類、影響を受けた選手名（該当する場合）、タイムスタンプ、および変更内容を記述した構造化された詳細レコード（例：変更前と変更後の結果の値）
- **審判結果の監査記録（別管理）** — 保存済みの審判結果に対するすべての変更は、サーバーが拒否した試行も含め、操作を行ったユーザーのメールアドレスと変更前後の値を保持する監査テーブルに追加で記録されます。これは、結果に争いが生じた場合にその経緯を再構成できるようにするためのものです。この記録はイベントの Organizer および Main Judge のみが読み取ることができ、本アプリ内に表示画面はありません
- **公開範囲** — アクティビティログの画面は Organizer および Main Judge が利用できます。ログ項目はイベント内に保存され、技術的には、同じイベントの承認済みメンバーが当社の API を通じて読み取ることが可能です
- **保持期間** — ログ項目および審判結果の監査記録は、イベントのレコードが存在する限り保持されます。これらはデータベース上の制約でイベントに紐づけられていないため、イベントを削除しても自動的には削除されません。5項をご参照ください

### 2.7 プッシュ通知データ

イベント関連の通知をお客様のデバイスに配信するため、本アプリは以下を保存します。

- **OneSignal Subscription ID** — 当社のプッシュ通知プロバイダ（OneSignal）が発行するデバイス固有の識別子。通知の送信先アドレスとしてのみ使用されます。
- **OneSignal external user ID** — お客様のアカウント ID で、Subscription ID と紐づけられ、デバイスを問わずお客様のアカウント宛てに通知を送信できるようにします。
- **Subscription のタイムスタンプ** — 最終更新時刻で、無効になった購読を検出するために使用されます

これらの値はお客様のアカウントプロフィールに保存されます。Subscription ID は、本アプリからサインアウトしたとき、同じデバイスで別のアカウントがサインインしたとき、および OneSignal がその購読はもはや有効でないと報告したとき（例：本アプリがアンインストールされた場合や、通知許可が取り消された場合）に自動的にクリアされます。

**注:** Apnea Comp は以前、プッシュ配信に Firebase Cloud Messaging（FCM）を使用していました。2026年5月をもって、プッシュ通知インフラは OneSignal へ移行されました。関連する第三者プロバイダの詳細については 4.3項をご参照ください。

### 2.8 デバイスのローカルストレージ

本アプリは、2 つの目的のために、お客様のデバイス上に限られたデータをローカルに保存します。

**オフラインバッファリング（Judge 結果）**

インターネット接続が断続的になる状況（プールおよびデプスの会場で一般的です）でも操作を継続できるようにするため、本アプリは審判結果が当社サーバーに到達する前に、一時的にお客様のデバイスのメモリに保持する場合があります。

- **場所** — 本アプリの実行中のメモリ内のみ。オフラインバッファリングされた審判結果は、デバイスの永続ストレージには書き込まれません。
- **タイミング** — オフライン状態で審判が結果の保存を試みた際に自動的に行われます。
- **保持期間** — 本アプリが結果を当社サーバーと同期するまで。同期はインターネットが復旧してから数秒以内に自動的に行われます。
- **公開範囲** — オフラインバッファリングされた結果は、同期が成功するまで、それを作成したデバイス上でのみ表示されます。同じイベントの他のデバイスには表示されません。
- **制約** — 同期が完了する前に本アプリが強制終了されたり、デバイスが再起動されたりすると、オフラインバッファリングされた結果は失われます。本アプリは該当する項目に「⛔ Offline」バッジを表示し、項目が保留中の間は本アプリを終了しないようユーザーに警告します。

**ログイン時の利便性（Remember Email / Password）**

ログイン画面には、次回以降のログイン時に事前入力されるよう、認証情報をローカルに保存する 2 つの任意トグルがあります。

- **メールアドレスを記憶（Remember email）** — 有効にすると、お客様のメールアドレスがデバイスの標準ローカルストレージ（Android では SharedPreferences、iOS では NSUserDefaults）に保存されます。
- **パスワードを記憶（Remember password）** — 有効にすると、お客様のパスワードがデバイスの**セキュアキーストア**（iOS Keychain / Android EncryptedSharedPreferences、AES-256、オペレーティングシステムによって暗号化）に保存されます。平文で保存されることは決してなく、当社サーバーや第三者に送信されることもありません。同じデバイス上でログインフォームを事前入力し、セッションを復元する目的にのみ使用されます。
- **場所** — お客様のデバイス上のみ。この情報は当社サーバーや第三者に送信されません。
- **削除方法** — 次回のログイン時にオプションのチェックを外す、本アプリからサインアウトする（保存された認証情報がクリアされます）、または本アプリをアンインストールします。

**表示設定（Display Preferences）**

お客様のテーマ選択（ライト / ダーク / システム）とアプリの言語は、本アプリが起動間で記憶できるよう、ローカル（SharedPreferences）に保存されます。これらは設定項目のみであり、個人情報を含みません。

オフラインバッファリング、ログイン時の利便性、表示設定の保存のいずれも、第三者にデータを送信することはありません。

### 2.9 プロテストデータ

AIDA 大会規則（ルールブック 17.7）に基づきプロテストが提出されると、本アプリは以下を含む protest レコードを保存します。

- **プロテスト理由** — プロテストを提出する者が入力する自由記述テキスト
- **選手の署名** および、該当する場合は **Jury の署名** — 手書きの画像としてキャプチャされ、protest レコード内に（base64 でエンコードして）保存されます。チェックインの署名パッドとは異なり、署名されたプロテストは公式の競技記録の一部であるため、**プロテストの署名は保持されます**。
- **生成されたプロテスト用紙** — 理由と署名を埋め込んだ PDF で、当社のバックエンドのファイルストレージ（Supabase Storage）に保存されます
- **決定および修正内容** — jury の決定（accepted / rejected / withdrawn）、および承認された場合は修正後の結果（card、RP、remarks）

**公開範囲** — protest レコードは、イベントのスタッフ（Organizer、Main Judge、Judge）およびそのプロテストが関係する選手に表示されます。プロテストの活動はプッシュ通知をトリガーします（3項参照）。

### 2.10 提出書類（同意書および医療診断書）

選手がイベントに参加する際、本アプリは、主催者が要求する同意および資格に関する書類を収集し保存する場合があります。

- **大会参加申込書** — 性別、生年月日、出生国、国籍、種目別の自己ベスト記録、および**ご自身が選択して申告する健康関連の履歴**（最近の圧力損傷 / 気圧外傷の日付、最近のブラックアウトの日付、最近の健康診断の日付）。
- **肖像権同意書** および **責任免除同意書** — 本人の氏名、イベント名および場所、署名日、ならびに手書きの署名。
- **医療診断書（任意）** — 検診 / 発行日、ならびに医師の氏名、電話番号、手書きの署名を含む、医師による適性診断書。ご自身の健康を証明する書類であるため、これは**センシティブな健康情報**です。医療診断書は 1 年間有効であり、ご自身の選択により、今後のイベントで再利用できるようご自身のプロフィールに保存されます。
- **署名** — 選手、証人、および医師の署名は手書きの画像としてキャプチャされ、生成される書類に埋め込まれます。チェックインの署名とは異なり、これらの署名は同意記録の一部として**保持されます**。
- **アップロードされたファイル** — 本アプリ内で直接記入する代わりに、書類を写真またはスキャンとして提出する場合、その画像ファイルが保存されます。
- **生成された PDF** — 本アプリ内で記入した書類は PDF としてレンダリングされ、当社のバックエンドのファイルストレージ（Supabase Storage）に保存されます。

**公開範囲** — 提出されたイベント書類は、検証のためにイベントの Organizer および Main Judge が閲覧でき、これらの担当者は書類を ZIP アーカイブとして一括ダウンロードすることもできます。負傷またはブラックアウトの日付を申告した場合、スタッフに対して医療診断書を手動で検証するよう案内が表示されます。

**リマインダー** — 必須書類をイベントの前日までに提出しなかった場合、不足している書類を案内するプッシュ通知を受け取ることがあります。

**この情報を保持する理由** — 医療診断書、および大会参加申込書で申告された健康履歴は、お客様がフォームに記入して提出することを選択された時点で与えられる、お客様の**明示的な同意**に基づいて処理されます。11項に記載の連絡先までご連絡いただくことで、この同意はいつでも撤回できます。ただしその場合、AIDA 規則に基づき、運営者がお客様の大会への出場を認められなくなることがあります。

### 2.11 イベント中の安全および医療に関する記録

フリーダイビングの大会は安全が最も重要であり、AIDA 規則は、特定の医療上の事象を記録し対応することを求めています。そのため本アプリは以下を保存します。

- **リスクマーキング** — 安全ダイバーおよび審判が備えられるよう、Organizer、Main Judge、Judge または Safety のスタッフが演技前に選手に設定できる安全上のフラグ（なし / イエロー / オレンジ / レッド）。このフラグは、本アプリおよびペアリングされた Apple Watch 上でイベントスタッフに表示され、当該選手のイベントエントリーとともに保存されます。
- **ブラックアウト後のフォローアップ記録（BO 事後確認）** — 選手にブラックアウトが発生した場合、またはリスクが高いとマークされた場合、Organizer または Main Judge は、フォローアップの判断（「cleared（出場可）」または「medical re-examination required（再検査が必要）」）、任意の医療メモ、判断した者、および判断した日時を記録します。この記録は、同じイベントの後日のチェックイン時に再度表示されます。
- **医療診断書の無効化** — 再検査が必要となった場合、Organizer または Main Judge はお客様の医療診断書を無効化することができます。当社は、無効化の日時、無効化した者、および入力された理由を、イベントへの提出分とお客様のプロフィールに保存された原本の双方に保存し、プッシュ通知でお客様にお知らせします。理由そのものは通知には含まれません。無効化は、同じ役割の担当者が取り消すことができます。

**この情報を保持する理由** — イベントを安全に運営し、AIDA 大会規則を遵守するためです。これは健康に関する情報であるため、当社は、安全が最も重要となる競技において選手および安全スタッフの生命に関わる利益を保護するために必要な範囲で、また、AIDA イベントへの出場にあたりお客様が同意される大会規則によって求められていることを根拠として、これを処理します。アクセスはイベントの Organizer および Main Judge に限定されます。ただしリスクマーキングについては、安全に関わるスタッフも閲覧できます。これらの記録はイベントのレコードの一部として保持され、イベントが削除されると削除されます。

### 2.12 お知らせおよびスタッフ間メッセージ

本アプリには、イベントの掲示板（Board。Organizer または Main Judge が作成し、そのイベントの全員が閲覧できるお知らせ）と、配信（Dispatch。イベントスタッフが選択したスタッフに送るメッセージ）の機能があります。各メッセージについて、当社は本文、送信者の氏名とメールアドレス、送信時刻、および配信（Dispatch）の場合は受信者のメールアドレスの一覧を保存します。メッセージがプッシュ通知として送信される場合、その本文は記載されたとおりに OneSignal に渡され、翻訳は行われません。メッセージはイベントの一部であり、イベントが削除されると削除されます。

### 2.13 除外記録

Organizer がお客様をイベントから除外した場合、本アプリの自動的な選手マッチングによってお客様が再び追加され、Organizer の判断が意図せず取り消されることのないよう、本アプリはその除外の記録を保持します。この記録には、お客様のメールアドレス、AIDA 選手 ID、氏名を正規化した値、除外を行った者、Organizer が入力した理由（入力された場合）、および日時が含まれます。この記録は、お客様がメンバーでなくなった後もそのイベントについて保持され、期限による自動削除は行われません。Organizer は、お客様に新しい個人用招待コードを発行することでこれを解除できます。5項をご参照ください。

### 2.14 Apple Watch コンパニオン

本アプリには Apple Watch コンパニオンが含まれ、Start List を表示するほか、Apple Watch Ultra では、潜水中に水深、潜水時間、水温を表示するダイブ画面を提供します。Watch はこのためにモーションとフィットネス（Motion & Fitness）の権限を求めます。**水深、水温、潜水時間は Watch 上でのみ表示されます** — これらは iPhone、当社サーバー、AIDA、その他のいかなる相手にも送信されず、保存されることもありません。データは一方向にのみ流れます。iPhone から Watch へ、イベント名、お客様の役割、お客様の氏名、および Start List（安全上のリスクマーキングを含む）が送信されます。

## 5. データの保持

- **アカウントデータ** — お客様のアカウントが存在する間、保持されます。アカウントを削除すると、サインインの認証情報およびプロフィール（表示名、プロフィール画像、連携された AIDA 選手 UUID、プッシュ購読、言語設定）が削除されます。イベントの公式な競技記録の一部を構成する記録 — イベントのメンバーシップ、結果、チェックイン、アクティビティログの項目、プロテスト、および提出書類 — は、お客様が使用したメールアドレスによって識別されており、アカウントの削除によっては削除されません。これらは、それぞれの基準（イベントの削除、または以下に記載する書類の保持期間）に従って削除されます。より早い削除をご希望の場合は、11項に記載の連絡先までご連絡ください。
- **イベントデータ**（選手、結果、チェックイン状況、プロテスト、書類、お知らせおよびスタッフ間メッセージ、ブラックアウト後のフォローアップ記録） — イベント運営者がイベントを削除すると自動的に削除されます。
- **アクティビティログおよび審判結果の監査記録** — イベントのレコードが存在する限り保持されます。これらはデータベース上の制約でイベントに紐づけられていないため、イベントを削除しても自動的には削除されません。削除が必要な場合は、11項に記載の連絡先までご連絡ください。
- **除外記録** — Organizer がお客様をイベントから除外した場合、自動的な再登録によって Organizer の判断が取り消されることのないよう、当社はその除外の記録（お客様のメールアドレス、AIDA 選手 ID、氏名キー、除外を行った者、および入力された理由）を保持します。この記録は無期限に保持され、当該 Organizer が発行する新しい個人用招待コードによってのみ解除できます。
- **一括ダウンロード用アーカイブ** — Organizer または Main Judge がイベントのすべての書類またはプロテスト用紙を ZIP として一括ダウンロードすると、そのアーカイブは当社のファイルストレージに書き出され、10 分で失効するリンクを通じて共有されます。書類のアーカイブは 1 日後に削除され、プロテストのアーカイブは 30 日後に削除されます。
- **プロテストデータ**（理由、署名、決定） — イベントの一部として保持され、運営者がイベントを削除する際にイベントとともに削除されます。当社のファイルストレージに保存された生成済みのプロテスト PDF は、個々のプロテストが削除されると除去され、いかなる場合でも **生成から30日後に自動的に削除されます**。protest レコード自体 — 理由、決定、および保存された署名を含みます — には期限がなく、PDF が削除された後も、イベントが削除されるまで保持されます。
- **提出書類**（大会参加申込書、肖像権同意書、責任免除同意書、およびイベントに提出された医療診断書） — イベントの一部として保持され、**イベント終了の15日後に自動的に削除されます**。ご自身のプロフィールに保存した医療診断書は、その 1 年間の有効期間中は保持され、いつでも撤回することができます。
- **OneSignal Subscription ID** — 本アプリからサインアウトしたとき、同じデバイスで別のアカウントがサインインしたとき、または OneSignal が次にその購読はもはや到達不能であると報告したとき（例：本アプリがアンインストールされた場合や、通知許可が取り消された場合）にクリアされます。それまでの間、この識別子はお客様のプロフィールに保存されたままとなります。
- **ローカルに保存された認証情報**（Remember email / Remember password） — お客様がオプションを無効にするか、サインアウトするか、本アプリをアンインストールするまで、お客様のデバイスに保持されます。
- **オフラインバッファリングされた結果** — デバイスのメモリ内にのみ保持されます。インターネットが復旧してから数秒以内に当社サーバーに同期されるか、同期前に本アプリが終了されると失われます。
- **認証トークン** — 短命であり、自動的に更新または期限切れになります。

## 6. データセキュリティ

当社は、複数の層のセキュリティによってお客様の情報を保護します。

### 転送と保存

- すべてのデータは暗号化された HTTPS 接続で転送されます
- データは当社のインフラプロバイダ（Supabase）によって保存時に暗号化されます
- パスワードは業界標準のアルゴリズムでハッシュ化され、平文のパスワードを保存することは決してありません

### データベースレベルのアクセス制御

- ユーザーまたはイベントのデータを含むすべてのテーブルに、データベースレベルで **Row-Level Security（RLS）** が適用されます
- ユーザーは、自分が属するイベントのデータにのみアクセスできます
- 承認待ちまたは未承認のメンバーは、イベントデータにアクセスできません
- 権限はログイン時だけでなく、すべてのクエリで検証されます

### 役割ベースの権限

- **Organizer / Main Judge** — イベント、メンバー、競技データの管理、アクティビティログの閲覧、提出書類の確認、ブラックアウト後のフォローアップ判断の記録、手動プッシュ通知の送信が可能です。Organizer は **Observer** として参加することもでき、その場合はイベントのメンバー一覧に表示されませんが、権限は同じです。
- **Judge** — 競技結果の閲覧および入力、リスクマーキングの設定、プロテストの閲覧が可能
- **Safety** — イベントデータの閲覧およびリスクマーキングの設定が可能
- **Photo** — Start List の閲覧、および自身が撮影を担当する選手の記録が可能
- **Staff** — イベントデータの閲覧が可能
- **Athlete** — Start List、本人の競技結果、本人が提出した書類、および本人に関わるプロテストへの読み取り専用アクセス
- 権限はイベントごとに限定され、あるイベントの審判は別のイベントへのアクセス権を持ちません

### AIDA API トークンの保護

- AIDA International との同期に使用される AIDA API トークンは、いかなるアプリケーションの役割も直接読み書きできない、分離され施錠されたデータベーステーブルに保持されます。既定ではすべてのアクセスが拒否され、制限されたサーバー側の関数を通じてのみ許可されます。トークンは、その他のすべてのデータと同様に、当社のインフラプロバイダによって保存時に暗号化されます。
- トークンを取得できるのは main_judge および organizer の役割のみであり、制限されたデータベース関数を通じて強制されます
- その他の役割（judge、staff、athlete）は、イベントの他のデータにアクセスできる場合でも、トークンにアクセスできません
- トークンはユーザーインターフェース上でマスクされ、ユーザーが明示的に表示を選択した場合にのみ表示されます

### セッションとアクセス

- 認証トークンは短命であり、自動的に更新されます
- ユーザーがイベントから削除されると、アクセス権はリアルタイムで取り消されます
- アカウントの認証情報はお客様の責任であり、決して共有しないでください

当社はお客様の情報を保護するために合理的な対策を講じていますが、完全に安全なシステムは存在しません。お客様は、ご自身のアカウントの認証情報を秘密に保ち、不審な活動を報告する責任を負います。

## 9. 国際的なデータ移転

本アプリは、当社のサービスプロバイダが運営する地域でデータを処理および保存する場合があります。Supabase のデータは韓国（ソウルリージョン）に保存されています。プッシュ通知は OneSignal を通じて配信され、OneSignal はグローバルに運営されており、米国およびそのインフラが所在するその他の地域で通知のメタデータを処理する場合があります。OneSignal はさらに、通知を Apple Push Notification service（APNs）および Firebase Cloud Messaging（FCM）を通じて転送し、これらもグローバルに運営されています。エラー・クラッシュ診断は Sentry により米国で処理され、当該レポートには個人情報が含まれないよう設定されています（4.3項参照）。本アプリをご利用いただくことにより、お客様は、お客様のデータがこれらの地域に移転され処理されることに同意したものとみなされます。
